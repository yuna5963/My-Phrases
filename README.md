# My Phrases — 英語チャンク練習 PWA

日常英語の**チャンク（語・型）と例文**を自分のデッキに貯め、**SRSで反復練習**し、
**AI英語コーチとの会話で実際に使い**、足りなかった表現を**AIで教材化してデッキに追加する**——
「貯める → 練習する → 使う → 増やす」の学習サイクルがアプリ内で完結する、一人用のスマホ向けPWAです。

当初は「Notionのフレーズ集を取り込んで瞬間英作文するアプリ」でしたが、
現在は教材の追加・編集・練習・アウトプットまでを一貫して担う学習アプリに育っています。
Notionは取り込み元のひとつ（任意）です。

```
貯める   デッキに追加（Notion / CSV / アプリ内で手動・AI教材化）
  ↓
練習する  SRSが自動出題（今日の練習・瞬間英作文・穴埋め・音読・流し聞き）
  ↓
使う     チャット練習（AIコーチとの英会話にチャンクを実戦投入）
  ↓
増やす   足りなかった表現 → 表現ストック → AIが教材化してデッキへ
  ↺ 先頭へ戻って反復
```

## できること

**練習（オフラインで動作）**
- **今日の練習** — SRS（Leitnerボックス）の期日カードを、習熟度に応じた形式で自動出題
- **瞬間英作文** — 日本語→英語の即作文。チャンク→例文ネットワークで答え合わせ
- **文脈穴埋め** — 例文中のチャンクを伏せ字にして想起
- **連続再生 / 再現練習** — チャンク→例文を数珠つなぎで流し聞き（Word Spark: 読み上げ同期ハイライト、
  シラブル音節カナ表示、画面を暗くして再生）／日本語を聞いてタッチで答え合わせ
- **長文音読** — お手本再生→続けて音読

**AI機能（Gemini API・無料枠で運用、キーは端末内にのみ保存）**
- **チャット練習** — AI英語コーチとの英会話に、SRSが選んだチャンクを織り込んで「使う」練習。
  終了時に日本語のまとめと、デッキ未収載の**追加候補チャンク**を提案
- **教材化** — 表現ストックに貯めた表現へ、AIが和訳・例文・シラブルカナ・分類を補完し、
  プレビューで確認・修正してデッキへ直接追加
- **AI長文作成** — デッキのチャンク3〜5個を織り込んだ音読用の長文を生成
- **無料枠の残り目安** — 端末内でAPIリクエスト数を日次集計し「残り 約n回」を表示

**教材管理**
- **表現ストック** — チャットで出会った表現や自分で思いついた表現のメモ置き場（教材化の入口）
- **アプリ内で編集・削除・手動追加** — カナの手直しや不要教材の整理がCSV往復なしで完結
- **CSV入出力** — デッキ全件のバックアップ／再取り込み（マージ・全置換）。Notionエクスポート（.zip）もそのまま読める
- 学習進捗は端末内（IndexedDB）に保存。再取り込みしてもIDキーで進捗は保持

## セットアップ

```bash
npm install
npm run dev        # 開発サーバ（スマホ幅で確認）
```

アプリはホーム画面に追加してPWAとして使います。AI機能を使う場合は
[Google AI Studio](https://aistudio.google.com/apikey) で無料のAPIキーを取得し、【設定】→「チャット練習（AI）」に貼り付けます
（キーは端末のlocalStorageにのみ保存され、Google以外へは送信されません）。

## 教材の入れ方

次のどれでも。すべて端末内（IndexedDB）に保存され、以降は**練習系の機能は完全オフライン**で動きます。

1. **アプリ内で追加** — チャンク一覧の「＋ 追加」（全フィールド手動）、
   または表現ストック→「✨ 教材化」（英文だけ入れればAIが補完）
2. **CSVを直接取り込み** — 【設定】→「フレーズの取り込み」。列構成はアプリの
   CSVバックアップと同一なので、バックアップ→編集→再取り込みの往復ができます
3. **Notionエクスポート** — DBの「•••」→ エクスポート →「Markdown & CSV」でDLした
   `.zip` をそのまま選択（解凍不要・APIキー不要）

> 取り込みは**マージが既定**（ID一致は上書き、アプリ内で追加した教材は保持）。
> 初期状態はサンプルデータで、取り込むと置き換わります。

## 既知の注意点

- **画面オフでの連続再生は不可**（Web Speech APIの制約）。代替として「🌙 暗くして再生」
  （全画面黒オーバーレイ＋Wake Lock）を用意
- **iOS Safari**: TTSは最初の再生にユーザー操作（ボタンタップ）が必要
- 音声の種類・品質は端末依存（設定画面で選択可。英語音声が無い場合は診断とインストール案内を表示）
- AI機能のみネットワークが必要。無料枠のレート上限（429）時は時間を置く
- チャンク使用検出は正規化＋単語境界の一致のみで、**活用形は検出しない**
