## 1. 背景・目的

利用者はNotionのデータベース「🔠 フレーズ集」に、日常英語の**チャンク（語・型）と例文**、
日本語訳をほぼ毎日蓄積している。しかしNotionは情報を「貯める」用途には向くが、「反復練習する」用途には向かない。

本システムは、蓄積したチャンク資産（1チャンク + 例文最大5 + メタ情報）を取り込み、
スマートフォンで手軽に
**今日の練習**（SRSの期日カードを習熟度に応じた形式で自動出題）・
**瞬間英作文**（日本語→英語を即座に生成し、チャンク→5例文を逐次で答え合わせ）・
**文脈穴埋め**（例文中のチャンクを伏せ字にして想起）・
**長文音読**（長文のお手本再生→続けて音読）・
**連続再生 / 再現練習**（チャンク→5例文を数珠つなぎで流し聞き／日本語を聞いてタッチで答え合わせ）を
行えるようにすることを目的とする。チャンクは Type / Category / Level / Priority のメタ情報で
一覧・再生を絞り込める。

### ゴール
- 通勤・隙間時間にスマホで反復練習ができる
- Notionの蓄積を最小手間でアプリに反映できる
- 学習の進捗が記録され、復習すべきフレーズが自動で提示される
- 手を使えない場面でもフレーズを連続で流し聞きできる

## 2. 利用者・利用環境

| 項目 | 内容 |
|---|---|
| 主な利用者 | フレーズDBの所有者本人（英語学習者） |
| 端末 | スマートフォン（iOS Safari / Android Chrome）中心。PCブラウザも可 |
| 形態 | PWA（ホーム画面に追加してアプリのように使用） |
| ネットワーク | 初回読み込み後は**オフラインで動作**すること |
| 言語 | UIは日本語、学習対象は英語 |

## 3. 用語定義

| 用語 | 定義 |
|---|---|
| チャンク | 学習単位。見出しの語・型（en）・日本語訳（ja）・例文最大5（en/ja のペア）・メタ情報を持つ。本書では旧称「フレーズ」と同義 |
| 例文 | チャンクに紐づく英文と、その日本語訳のペア（最大5）。`examples:{en,ja}[]` |
| メタ情報 | チャンクの分類: Type（Nuance/Pattern/Chunk/Connector/Phrase。特別値 **Long Reading** は長文音読モード専用）・Category・Level（Basic/Core/Advanced）・Priority（★）・Note |
| 瞬間英作文 | 日本語訳を見て英語を即座に生成する練習。チャンク→例文1〜5を逐次で「日本語→タッチ→英文」と答え合わせする |
| モデリング | チャンクと5例文を、お手本を聞きながら声に出して音読する練習。独立モードは廃止し「今日の練習」の新規カード向け形式として継続 |
| 長文音読 | `Type = Long Reading` の長文だけを対象に、本文のお手本音声を聞いて続けて音読する練習 |
| 音節カナ（シラブル音節カナ） | 英文の発音を、アメリカ英語ベースで音節ごとにカタカナ表記したもの。強勢は `*…*` で囲み太字表示。英文の下に小さく添える（記法は `docs/シラブル音節記法.md`） |
| 連続再生プレイヤー | 一覧から起動し、チャンク→例文1→…を自動で次々読み上げる流し聞き機能 |
| 再現練習 | 連続再生以外の通常時に、日本語訳を聞いて自分で英語を再現→タッチで英文を表示し答え合わせ→さらにタッチで次へ進む練習（日本語訳ON時。自動送りはしない） |
| 暗くして再生 | 連続再生中に画面を黒く覆い、誤タッチを無効化して聴くモード |
| 覚えた | チャンク単位の手動チェック（SRSの習得済みとは別の主観マーク） |
| 自信なし | 「覚えた」が未チェックのチャンクを指す絞り込み条件 |
| SRS | 間隔反復学習（Spaced Repetition System）。Leitnerボックス方式 |
| インポート | NotionエクスポートまたはCSVファイルをアプリに読み込むこと |
| サンプルデータ | 未インポート時に表示される初期内蔵データ |

## 4. 機能要件

### 4.1 取り込み（インポート）
- FR-01: NotionエクスポートまたはCSVファイルをアプリのUIから取り込めること。
- FR-02: 取り込み対応形式は **`.csv`（直接）/ `.zip`（Markdown & CSV一括）/ `.md`** とする。
- FR-03: `.zip` は解凍せずそのまま取り込めること（アプリ内で解凍）。
- FR-04: `.md` / `.csv` は複数ファイルの同時選択に対応すること。
- FR-05: 取り込んだデータは端末内に永続保存し、再起動・オフラインでも利用できること。
- FR-06: 再取り込み時は全件を入れ替える（元データ側の削除を反映）。ただし学習進捗は保持すること。
- FR-07: 取り込みデータを消去し、サンプル表示に戻せること。
- FR-08: APIキーやサーバ連携、ターミナル操作を必須としないこと。
- FR-09: CSVは新フォーマット（`ID, Type, Category, Level, Priority, Chunk, 日本語, Example1, 日本語訳1, … Example5, 日本語訳5, Note`）に対応し、`Example{n}` と `日本語訳{n}` を例文ペアとして読み取ること。任意で音節カナ列（チャンク=`音節`、例文=`音節{n}`）を読み取れること（FR-97〜101）。旧フォーマット（`フレーズ`/`日本語訳`/単一例文）も後方互換で読めること。

### 4.2 瞬間英作文
- FR-10: **「日本語訳を見て英作文 → タッチで答え合わせ」を、チャンク → 例文1 → … → 例文5 と1枚のカードで続けて練習**できること。
  各ステップは日本語訳のみ表示（＋読み上げ）→ タッチ → 英文＋カナ表示（＋読み上げ）→ タッチで次の項目へ。英文はタッチするまで非表示。自動では進まないこと。
- FR-11: 日本語訳のない例文は出題から除外すること（和訳は元データ側で用意する。C-08）。
- FR-12: 項目の進み（n / 総数）とチャンクのメタ情報（Type/Category/Level/Priority）をカード上に表示すること。
- FR-13: 最後の項目まで答え合わせしたら、自己採点を3段階（できた / あいまい / できなかった）で記録できること。
- FR-14: 「できた」以外はそのセッション内で再出題されること。
- FR-15: 出題キューは **Type → Category でまとめ直し**、次のチャンクへは同じタイプ・同じカテゴリのものへ優先的に遷移すること
  （グループはSRSの弱い順での初出順、グループ内も弱い順を保つ）。
- FR-16: 開示した英文は再生ボタン（🔊）で**何度でも聞き直せる**こと（押してもカードは進まない）。

### 4.3 モデリング練習【v0.6で削除】
- ~~FR-70〜73~~: 発音練習（§4.4）と実装・目的が重複するため**モードとして削除**。
  「チャンク＋5例文をお手本に音読」する練習は発音練習および「今日の練習」（§4.13）の**モデリング形式**（新規カード向け）として継続する。

### 4.4 発音練習【v0.6.1で削除】
- ~~FR-20〜26~~: チャンク詳細（§4.14。`ModelCard` のチャンク＋5例文・個別再生）と連続再生（§4.6）で同等のことができ**機能が重複するため、独立モードとして削除**。
  お手本を聞いて反復する「モデリング形式」は「今日の練習」（§4.13）の新規カード向けに継続する。
  なお「覚えた」チェックはチャンク一覧（FR-45）とチャンク詳細（FR-122）で引き続き操作できる。

### 4.5 長文音読
- FR-91: `Type` が **「Long Reading」** のフレーズのみを対象に、長文本文をお手本として提示・読み上げできること。
- FR-92: 本文（英文）をTTSで読み上げ・停止できること。読み上げ中は端末のスリープを抑止すること。
- FR-93: 本文の和訳を必要に応じて表示・非表示に切り替えられること。
- FR-94: 前後の長文へ手動で移動でき、移動・離脱時は読み上げを停止し和訳表示をリセットすること。
- FR-95: 対象（Long Reading）が0件のときは、その旨と取り込み方法の案内を表示すること。
- FR-96: 長文音読の対象（Long Reading）は、瞬間英作文・各一覧・ホームの集計からは除外すること。

### 4.6 連続再生プレイヤー / 再現練習
- FR-80: チャンク一覧／例文一覧でタップしたチャンクを起点に、一覧の並び順で「チャンク→例文1→…」を自動的に次々読み上げること。
- FR-81: 読み上げ項目（チャンク / 例文 / 日本語訳）を個別にON/OFFできること。
- FR-82: 日本語訳の読み上げ音声が端末に無い場合は、日本語訳の再生を無効化し理由を表示すること。
- FR-83: リピート（末尾で先頭へ戻る）/ シャッフル（ランダム順）を切り替えられること。
- FR-84: 前後のチャンクへ手動で移動できること。
- FR-85: 連続再生中は端末のスリープを抑止し、画面消灯で再生が止まらないようにすること。
- FR-86: **「暗くして再生」** モードで画面を黒く覆い、聴取中の誤タッチを無効化できること。
  解除は**2本指の同時タッチ**のみで行い、1本指タッチでは解除されないこと。再生停止で暗転も解除すること。
- FR-87: 連続再生で使う各設定（読み上げ項目・リピート・シャッフル）は端末内に永続化すること。
- FR-88: 再生の間（ま）は、1項目内（和訳↔英文）を **1.5秒**、次の項目（次の例文/チャンク）へを **2秒** 空けること。
- FR-89: 日本語訳ONのときの読み上げ順は **「和訳→英文」** とすること（OFF時は英文のみ）。
- FR-90: **自動再生・暗くして再生を除く通常時** かつ 日本語訳ON のときは **再現練習** とし、
  「日本語訳の表示・再生 → タッチ → その項目の英文を表示・再生 → **タッチで次の項目の日本語訳へ**」と進めること。
  英文はタッチするまで非表示とし、自動では次の項目へ進まないこと（項目送りはタッチで行う）。

### 4.7 学習管理（SRS）
- FR-30: フレーズごとに学習状態（ボックス・次回出題日・正誤回数・最終学習日）を保持すること。
- FR-31: 採点結果に応じて次回出題日を自動調整すること。
- FR-32: 「今日の出題」は出題対象（期限到来＋新規）から、設定枚数を上限に提示すること。
- FR-33: 連続学習日数（ストリーク）を記録・表示すること。
- FR-34: 学習進捗を全消去できること。
- FR-35: SRSとは別に、チャンク単位の主観的な「覚えた」状態を保持できること。

### 4.8 チャンク一覧・検索
- FR-40: 全チャンクを一覧表示できること。
- FR-41: チャンク英語 / 日本語 / 例文（英・和）のキーワードで絞り込めること。
- FR-42: **Type / Category / Level / Priority のファセット**および「自信なし」で絞り込めること（各ファセットは値を1つ選択、横断はAND）。ファセットの選択肢はデータから動的に生成すること。
- FR-43: 各チャンクをタップで**チャンク詳細**（§4.14）へ遷移できること（絞り込み結果と起動元の一覧を戻り先として渡す）。連続再生プレイヤーへは、各行の「▶」ボタンでワンタップで直接遷移できること。
- FR-44: 習得済みチャンクを判別表示すること。
- FR-45: 各チャンクに「覚えた」チェックを付け外しでき、その場で単発のTTS再生もできること。
- FR-45b: 件数が多いため**ページング**（1ページ100件）で表示し、フィルタ変更時は先頭ページに戻すこと。例文一覧（FR-48）と共通のページ送りUI（`Pager`）を用いること。

### 4.9 例文一覧
- FR-46: チャンク一覧と**同一の上部フィルタ**（キーワード検索・自信なし・ファセット）を流用して絞り込めること。
- FR-47: 絞り込み済みチャンクの例文1〜5を**平坦に展開**し、英文＋日本語訳を一覧表示できること（空の例文は除外）。各行に出典のチャンク英語を併記すること。
- FR-48: 件数が多いため**ページング**（1ページ100件、チャンク一覧の FR-45b と同UI）で表示し、フィルタ変更時は先頭ページに戻すこと。
- FR-49: 各例文をタップで**例文カード**（§4.17）へ遷移でき（戻り先は例文一覧）、各例文を単発でTTS再生もできること。チャンク詳細へは例文カード内の導線から遷移する。

### 4.10 設定
- FR-50: TTSの音声・再生速度・自動読み上げの有無、および**音節カナ表示の有無**（FR-101）を設定できること。
- FR-51: 1セッションの出題枚数を設定できること。
- FR-52: 練習対象とするステータスを選択できること。
- FR-53: 設定は端末内に永続化すること。
- FR-54: 再生速度の調整は**英語の読み上げのみ**に適用し、日本語訳は常に等倍で再生すること。

### 4.11 ホーム
- FR-60: 統計（今日の出題/新規/習得済み/今日やった/登録数/連続日数）を表示すること。
- FR-61: 各練習モード（瞬間英作文 / 文脈穴埋め / 長文音読）へ遷移できること。
- FR-62: 未インポート時はインポートを促す導線を表示すること。
- FR-63: 統計の直下に**「今日の練習」**（§4.13）への最上位導線を、期日到来件数つきで表示すること。

### 4.12 シラブル音節カナ表示
- FR-97: チャンク／例文の英文に、アメリカ英語ベースの**シラブル音節カタカナ**を任意で持たせ、英文の**下**に小さく表示できること。
- FR-98: 音節カナ内の**強勢（ストレス）**を強調表示できること（記法 `*…*`＝太字表示）。
- FR-99: 音節カナデータは**CSVの任意列**（チャンク=`音節`、例文=`音節1〜音節5`）で投入でき、未入力の場合は英文のみを表示すること（後方互換）。
- FR-100: 音節カナの表示はカード／詳細／練習画面（瞬間英作文・今日の練習・文脈穴埋め・チャンク詳細・長文音読・フレーズ再生）**および例文一覧**の行に対応すること。チャンク一覧の行は一覧性維持のため対象外とする。
- FR-101: 音節カナ表示の ON/OFF を設定で切り替えられ（既定ON）、端末内に永続化すること。

> 記法・作成手順・ChatGPT量産プロンプトは `docs/シラブル音節記法.md` に規定する。

### 4.16 読み上げハイライト（Word Spark）
- FR-140: 英文の読み上げ中、**現在発話中の単語**をマーカー風（背景色＋文字色）に強調表示できること。文字サイズは変えず、行の折り返しが揺れないこと。
- FR-141: 対象は**長文音読の本文**と**再現練習カード（ReproCard）の開示英文**（瞬間英作文・今日の練習・フレーズ再生の再現練習・「🔊もう一度」再生を含む）とする。日本語の読み上げは対象外。
- FR-142: 単語位置は TTS の boundary イベントに同期すること。イベントが発火しないエンジン（Android Chrome の Google TTS 等）では**推定タイミング**で単語を送ること（おおよその追従でよい）。推定の全体速度は**実際の発話時間の実測から自動較正**し（再生速度別に端末内へ永続化）、単語の配分は**音節数・強勢（機能語の弱形）・句読点ポーズ**を反映して英語のリズムに近づけること。
- FR-143: 読み上げの停止・終了・カード切替でハイライトを消すこと。
- FR-144: チャンク詳細・今日の練習の**例文一覧（5例文表示）**でも、各例文の🔊再生時に**その行だけ**ハイライトが進むこと（他の例文は表示のまま）。再生中に別の例文の🔊を押した場合はハイライトが移ること。

### 4.17 例文カード
- FR-150: 例文一覧でタップした例文を**1枚のカード**で練習できること。挙動は瞬間英作文の例文表示と同一
  （日本語訳表示・再生 → タッチ → 英文＋カナ表示・再生＋Word Spark ハイライト。「🔊もう一度」で聞き直し可）。
- FR-151: 「← 戻る / 進む →」で**絞り込み結果内の例文**を前後に移動できること。
- FR-152: 例文の出典（例文N・チャンク英語）を表示し、親チャンクの**チャンク詳細**（§4.14）への導線を持つこと。
- FR-153: 「← 一覧へ」で例文一覧に戻れること。

### 4.13 今日の練習（統合フロー）
- FR-110: SRSの期日到来カード（§4.7）を1つのセッションに集約し、カードごとの習熟度（Leitnerボックス）に応じた練習形式で自動出題できること。
- FR-111: 形式の出し分けは次のとおりとすること: 新規（未学習）=モデリング / box 0-1=再現練習 / box 2-3=瞬間英作文 / box 4以上=文脈穴埋め（穴埋めにできる例文がないチャンクは瞬間英作文）。
- FR-112: 形式はカード表示のたびに進捗から算出し、採点により box が変化した場合は同一セッション内の再出題でも形式が追従すること。
- FR-113: 採点は既存のSRS採点（FR-30〜31）に統合し、専用の進捗データを持たないこと。
- FR-114: 期日到来カードが0件のときは補充出題をせず、完了した旨を表示すること（既存の単独モードのランダム補充出題は従来どおり維持する）。
- FR-115: 現在の練習形式（モデリング/再現練習/瞬間英作文/文脈穴埋め）をカード上部にラベル表示すること。

### 4.14 チャンク詳細
- FR-120: チャンクの英語・音節カナ・日本語・メタ情報（Type/Category/Level/Priority）・補足メモ（note）・例文一覧（英・カナ・和、個別TTS再生つき）を1画面で確認できること。
- FR-121: 学習の記録（習熟度 box/5・「できた」「できなかった」回数・次回出題日）を表示すること。
- FR-122: 「覚えた」チェックを付け外しできること（FR-35と同一の状態）。
- FR-123: 画面下部から**連続再生プレイヤー**へ遷移でき、一覧から受け取った絞り込み結果（再生範囲）と戻り先をそのまま引き継ぐこと。
- FR-124: 一覧へ戻る導線を画面下部に持つこと（戻り先は起動元の一覧）。

### 4.15 文脈穴埋め
- FR-130: 例文中のチャンクを伏せ字にして表示し、文脈と日本語ヒント（チャンクの和訳）からチャンクを想起する練習ができること。
- FR-131: チャンクと例文のマッチングは**大文字小文字無視＋単語境界チェック**の部分一致のみとし、活用形の探索（ステミング）は行わないこと。アポストロフィの字種差（`'`/`’`）は吸収すること。
- FR-132: チャンクが見つかる例文を1つ以上持つフレーズだけを出題対象とし、1チャンクにつきマッチした例文から**ランダムに1つ**を出題すること（同一カードの表示中は固定）。
- FR-133: 開示後は例文全文（チャンク部分を強調表示）・音節カナ・TTS再生を提示し、3段階採点（FR-31）ができること。
- FR-134: 対象フレーズが0件のときはその旨を表示すること。
- FR-135: 「今日の練習」（§4.13）の box 4以上のカードにも同形式を適用すること。

## 5. 非機能要件

| 区分 | 要件 |
|---|---|
| NFR-01 オフライン | 初回読み込み後はネットワークなしで全機能が動作すること（PWA / Service Worker） |
| NFR-02 プライバシー | 学習データ・フレーズは端末内のみに保存し、外部送信しないこと |
| NFR-03 セキュリティ | クライアントにNotion APIキー等の秘密情報を持たせないこと |
| NFR-04 操作性 | スマホ縦持ちでの片手操作を前提としたモバイルファーストUI。各練習画面の離脱導線（「✕ やめる」「← 一覧へ」）は親指で届く画面**下部**に配置し、上部ヘッダーはタイトルと進捗の表示に限ること |
| NFR-05 インストール性 | ホーム画面に追加でき、スタンドアロン表示で起動できること |
| NFR-06 保守性 | 機能領域（SRS/保存/TTS/取り込み/画面）を分離した構成とすること |
| NFR-07 互換性 | 進捗はフレーズIDをキーに保持し、再取り込みで失われないこと |

## 6. 制約・前提

- C-01: 発音の自動採点（音声認識スコアリング）は本バージョンの対象外。採点は利用者の自己申告とする。
- C-02: TTSの音声品質・声の種類は端末の対応に依存する。
- C-03: iOS Safariでは、TTSの初回再生にユーザー操作（ボタンタップ）が必要。
- C-04: Notionとのリアルタイム自動同期は行わない。更新は利用者による再エクスポート＆再インポートで反映する。
- C-05: CSVは `ID` 列をそのまま id に採用する。`ID` 列が無い旧データや `.md` のテーブルでは英文から生成した安定IDで代替する（`.md` ページはファイル名末尾のNotionページIDを使用）。
- C-08: 例文の日本語訳は元データ（Notion/CSV）側で用意し、`日本語訳{n}` 列として保持する。空欄の場合、再現練習や和訳読み上げではその項目の和訳がスキップされる。
- C-06: **ブラウザのTTS（Web Speech API）は画面消灯・タブ非表示で再生が停止する仕様**であり、回避策がない。
  連続再生は画面を点灯したまま（Screen Wake Lock）行うことを前提とする。
- C-07: **「暗くして再生」はバックライト自体を消す機能ではない**（Webに明るさ制御APIが無い）。
  画面を黒く塗るのみで、有機ELでは実質消灯に近く、液晶では手動で明るさを下げると効果的。
- C-09: 読み上げハイライト（§4.16）の単語同期精度は端末依存。boundary イベントが発火しないエンジン
  （Android Chrome の Google TTS 等）では文字数×再生速度からの**推定**となり、実際の発音と多少ずれることがある。

## 7. 対象外（本バージョンのスコープ外）

- 音声認識による発音スコアリング
- 複数ユーザー/アカウント、クラウド同期、端末間同期
- フレーズのアプリ内編集・追加（編集はNotion側で行う）
- 学習リマインダー通知（プッシュ通知）
- AIによる例文生成・添削
- 画面を完全に消灯したままの音声再生（実音声ファイル方式が必要なため。下記将来拡張を参照）
