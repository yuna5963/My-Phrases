## 1. 背景・目的

利用者はNotionのデータベース「🔠 フレーズ集」に、日常英語の**チャンク（語・型）と例文**、
日本語訳をほぼ毎日蓄積している。しかしNotionは情報を「貯める」用途には向くが、「反復練習する」用途には向かない。

本システムは、蓄積したチャンク資産（1チャンク + 例文最大5 + メタ情報）を取り込み、
スマートフォンで手軽に
**今日の練習**（SRSの期日カードを習熟度に応じた形式で自動出題）・
**瞬間英作文**（日本語→英語を即座に生成し、チャンク→5例文を逐次で答え合わせ）・
**文脈穴埋め**（例文中のチャンクを伏せ字にして想起）・
**長文音読**（長文のお手本再生→続けて音読）・
**連続再生 / 再現練習**（チャンク→5例文を数珠つなぎで流し聞き／日本語を聞いてタッチで答え合わせ）・
**チャット練習**（AI英語コーチとの英会話で、覚えたチャンクを実際に使う）を
行えるようにすることを目的とする。チャンクは Type / Category / Level / Priority のメタ情報で
一覧・再生を絞り込める。

### ゴール
- 通勤・隙間時間にスマホで反復練習ができる
- Notionの蓄積を最小手間でアプリに反映できる
- 学習の進捗が記録され、復習すべきフレーズが自動で提示される
- 手を使えない場面でもフレーズを連続で流し聞きできる
- 覚えたチャンクを「使う」練習（会話でのアウトプット）ができ、足りない表現の発見が Notion への蓄積につながる

## 2. 利用者・利用環境

| 項目 | 内容 |
|---|---|
| 主な利用者 | フレーズDBの所有者本人（英語学習者） |
| 端末 | スマートフォン（iOS Safari / Android Chrome）中心。PCブラウザも可 |
| 形態 | **Androidネイティブアプリ（APK・主）** / PWA（ホーム画面に追加・従来） — 同一コードベース |
| ネットワーク | 初回読み込み後は**オフラインで動作**すること |
| 言語 | UIは日本語、学習対象は英語 |

## 3. 用語定義

| 用語 | 定義 |
|---|---|
| チャンク | 学習単位。見出しの語・型（en）・日本語訳（ja）・例文最大5（en/ja のペア）・メタ情報を持つ。本書では旧称「フレーズ」と同義 |
| 例文 | チャンクに紐づく英文と、その日本語訳のペア（最大5）。`examples:{en,ja}[]` |
| メタ情報 | チャンクの分類: Type（Nuance/Pattern/Chunk/Connector/Phrase。特別値 **Long Reading** は長文音読モード専用）・Category・Level（Basic/Core/Advanced）・Priority（★）・Note |
| 瞬間英作文 | 日本語訳を見て英語を即座に生成する練習。チャンク→例文1〜5を逐次で「日本語→タッチ→英文」と答え合わせする |
| モデリング | チャンクと5例文を、お手本を聞きながら声に出して音読する練習。独立モードは廃止し「今日の練習」の新規カード向け形式として継続 |
| 長文音読 | `Type = Long Reading` の長文だけを対象に、本文のお手本音声を聞いて続けて音読する練習 |
| 音節カナ（シラブル音節カナ） | 英文の発音を、アメリカ英語ベースで音節ごとにカタカナ表記したもの。強勢は `*…*` で囲み太字表示。英文の下に小さく添える（記法は `docs/シラブル音節記法.md`） |
| 連続再生プレイヤー | 一覧から起動し、チャンク→例文1→…を自動で次々読み上げる流し聞き機能 |
| 再現練習 | 連続再生以外の通常時に、日本語訳を聞いて自分で英語を再現→タッチで英文を表示し答え合わせ→さらにタッチで次へ進む練習（日本語訳ON時。自動送りはしない） |
| 暗くして再生 | 連続再生中に画面を黒く覆い、誤タッチを無効化して聴くモード |
| 覚えた | チャンク単位の手動チェック（SRSの習得済みとは別の主観マーク） |
| 自信なし | 「覚えた」が未チェックのチャンクを指す絞り込み条件 |
| SRS | 間隔反復学習（Spaced Repetition System）。Leitnerボックス方式 |
| インポート | NotionエクスポートまたはCSVファイルをアプリに読み込むこと |
| サンプルデータ | 未インポート時に表示される初期内蔵データ |
| チャット練習 | AI英語コーチと英語チャットで会話し、対象チャンクを実際に使う練習（§4.18）。AIは Gemini API の OpenAI 互換エンドポイント（無料枠）を利用 |
| 対象チャンク | チャット練習の1セッションで「使うこと」を狙うチャンク（SRSの弱い順に2〜6個）。チップ表示され、発話で使えると点灯する |
| フォーカス | チャンク詳細・例文カードから起動したとき「今これを練習したい」と指定されたチャンク（と例文の場面）。会話の中心になる |
| 追加候補 | チャット終了時のまとめでAIが提案する、フレーズ集に未収載の基本表現（`➕ 英語 — 日本語訳` 形式） |
| 表現ストック | 追加候補のうちチェックした表現を端末内に日付付きで蓄積する置き場（§4.19）。数日分をPCへ渡して例文作成→Notion追加する運用の中継地点 |

## 4. 機能要件

### 4.1 取り込み・書き出し（インポート / エクスポート）
- FR-01: NotionエクスポートまたはCSVファイルをアプリのUIから取り込めること。
- FR-02: 取り込み対応形式は **`.csv`（直接）/ `.zip`（Markdown & CSV一括）/ `.md`** とする。
- FR-03: `.zip` は解凍せずそのまま取り込めること（アプリ内で解凍）。
- FR-04: `.md` / `.csv` は複数ファイルの同時選択に対応すること。
- FR-05: 取り込んだデータは端末内に永続保存し、再起動・オフラインでも利用できること。
- FR-06: 再取り込みは**既定でマージ**とする（ID一致は上書き・アプリ内で追加した教材は保持・元データ側の削除は伝播しない）。**全置換**（削除を反映）もオプションとして選べること。いずれも学習進捗は保持すること。
- FR-06b: デッキ全件を**CSVでエクスポート（バックアップ）**でき、そのCSVを再取り込みすれば**ステータス・カナ含め完全に復元**できること。書き出しは OS の共有シート（メール・Drive 等）またはファイルダウンロードで行えること。
- FR-07: 取り込みデータ（アプリ内追加分を含む）を消去し、サンプル表示に戻せること。消去前にバックアップを促すこと。
- FR-08: APIキーやサーバ連携、ターミナル操作を必須としないこと。
- FR-09: CSVは新フォーマット（`ID, Type, Category, Level, Priority, Chunk, 日本語, Example1, 日本語訳1, … Example5, 日本語訳5, Note`）に対応し、`Example{n}` と `日本語訳{n}` を例文ペアとして読み取ること。任意で音節カナ列（チャンク=`音節`、例文=`音節{n}`）と `ステータス`・`カナ要確認`（FR-179）列を読み取れること（FR-97〜101）。旧フォーマット（`フレーズ`/`日本語訳`/単一例文）も後方互換で読めること。

### 4.2 瞬間英作文
- FR-10: **「日本語訳を見て英作文 → タッチで答え合わせ」を、チャンク → 例文1 → … → 例文5 と1枚のカードで続けて練習**できること。
  各ステップは日本語訳のみ表示（＋読み上げ）→ タッチ → 英文＋カナ表示（＋読み上げ）→ タッチで次の項目へ。英文はタッチするまで非表示。自動では進まないこと。
- FR-11: 日本語訳のない例文は出題から除外すること（和訳は元データ側で用意する。C-08）。
- FR-12: 項目の進み（n / 総数）とチャンクのメタ情報（Type/Category/Level/Priority）をカード上に表示すること。
- FR-13: 最後の項目まで答え合わせしたら、自己採点を3段階（できた / あいまい / できなかった）で記録できること。
- FR-14: 「できた」以外はそのセッション内で再出題されること。
- FR-15: 出題キューは **Type → Category でまとめ直し**、次のチャンクへは同じタイプ・同じカテゴリのものへ優先的に遷移すること
  （グループはSRSの弱い順での初出順、グループ内も弱い順を保つ）。
- FR-16: 開示した英文は再生ボタン（🔊）で**何度でも聞き直せる**こと（押してもカードは進まない）。

### 4.3 モデリング練習【v0.6で削除】
- ~~FR-70〜73~~: 発音練習（§4.4）と実装・目的が重複するため**モードとして削除**。
  「チャンク＋5例文をお手本に音読」する練習は発音練習および「今日の練習」（§4.13）の**モデリング形式**（新規カード向け）として継続する。

### 4.4 発音練習【v0.6.1で削除】
- ~~FR-20〜26~~: チャンク詳細（§4.14。`ModelCard` のチャンク＋5例文・個別再生）と連続再生（§4.6）で同等のことができ**機能が重複するため、独立モードとして削除**。
  お手本を聞いて反復する「モデリング形式」は「今日の練習」（§4.13）の新規カード向けに継続する。
  なお「覚えた」チェックはチャンク一覧（FR-45）とチャンク詳細（FR-122）で引き続き操作できる。

### 4.5 長文音読
- FR-91: `Type` が **「Long Reading」** のフレーズのみを対象に、長文本文をお手本として提示・読み上げできること。
- FR-92: 本文（英文）をTTSで読み上げ・停止できること。読み上げ中は端末のスリープを抑止すること。
- FR-93: 本文の和訳を必要に応じて表示・非表示に切り替えられること。
- FR-94: 前後の長文へ手動で移動でき、移動・離脱時は読み上げを停止し和訳表示をリセットすること。
- FR-95: 対象（Long Reading）が0件のときは、その旨と取り込み方法の案内・AI長文作成（§4.21）への導線を表示すること。
- FR-96: 長文音読の対象（Long Reading）は、瞬間英作文・各一覧・ホームの集計からは除外すること。
- FR-96b: 長文音読の画面から AI長文作成（§4.21）へ移動できること。

### 4.6 連続再生プレイヤー / 再現練習
- FR-80: チャンク一覧／例文一覧でタップしたチャンクを起点に、一覧の並び順で「チャンク→例文1→…」を自動的に次々読み上げること。
- FR-81: 読み上げ項目（チャンク / 例文 / 日本語訳）を個別にON/OFFできること。
- FR-82: 日本語訳の読み上げ音声が端末に無い場合は、日本語訳の再生を無効化し理由を表示すること。
- FR-83: リピート（末尾で先頭へ戻る）/ シャッフル（ランダム順）を切り替えられること。
- FR-84: 前後のチャンクへ手動で移動できること。
- FR-85: 連続再生中は端末のスリープを抑止し、画面消灯で再生が止まらないようにすること。
- FR-86: **「暗くして再生」** モードで画面を黒く覆い、聴取中の誤タッチを無効化できること。
  解除は**2本指の同時タッチ**のみで行い、1本指タッチでは解除されないこと。再生停止で暗転も解除すること。
- FR-87: 連続再生で使う各設定（読み上げ項目・リピート・シャッフル）は端末内に永続化すること。
- FR-88: 再生の間（ま）は、1項目内（和訳↔英文）を **1.5秒**、次の項目（次の例文/チャンク）へを **2秒** 空けること。
- FR-89: 日本語訳ONのときの読み上げ順は **「和訳→英文」** とすること（OFF時は英文のみ）。
- FR-90: **自動再生・暗くして再生を除く通常時** かつ 日本語訳ON のときは **再現練習** とし、
  「日本語訳の表示・再生 → タッチ → その項目の英文を表示・再生 → **タッチで次の項目の日本語訳へ**」と進めること。
  英文はタッチするまで非表示とし、自動では次の項目へ進まないこと（項目送りはタッチで行う）。
- FR-202: 【実験的】設定ONのとき、連続再生・長文音読の間ほぼ無音の音声をループ再生してブラウザの凍結を回避し、
  **画面オフでも読み上げの継続を試みる**こと（既定OFF。継続は端末・ブラウザ依存で**保証しない**＝C-15）。
  ON中は通知/ロック画面に再生中の教材を表示し、通知の一時停止・イヤホン取り外しでは再生全体を停止すること。
  「暗くして再生」（FR-86）と Wake Lock（FR-85）は従来どおり維持すること。

### 4.7 学習管理（SRS）
- FR-30: フレーズごとに学習状態（ボックス・次回出題日・正誤回数・最終学習日）を保持すること。
- FR-31: 採点結果に応じて次回出題日を自動調整すること。
- FR-32: 「今日の出題」は出題対象（期限到来＋新規）から、設定枚数を上限に提示すること。
- FR-33: 連続学習日数（ストリーク）を記録・表示すること。
- FR-34: 学習進捗を全消去できること。
- FR-35: SRSとは別に、チャンク単位の主観的な「覚えた」状態を保持できること。

### 4.8 チャンク一覧・検索
- FR-40: 全チャンクを一覧表示できること。
- FR-41: チャンク英語 / 日本語 / 例文（英・和）のキーワードで絞り込めること。
- FR-42: **Type / Category / Level / Priority のファセット**および「自信なし」で絞り込めること（各ファセットは値を1つ選択、横断はAND）。ファセットの選択肢はデータから動的に生成すること。
- FR-43: 各チャンクをタップで**チャンク詳細**（§4.14）へ遷移できること（絞り込み結果と起動元の一覧を戻り先として渡す）。連続再生プレイヤーへは、各行の「▶」ボタンでワンタップで直接遷移できること。
- FR-44: 習得済みチャンクを判別表示すること。
- FR-45: 各チャンクに「覚えた」チェックを付け外しでき、その場で単発のTTS再生もできること。
- FR-45b: 件数が多いため**ページング**（1ページ100件）で表示し、フィルタ変更時は先頭ページに戻すこと。例文一覧（FR-48）と共通のページ送りUI（`Pager`）を用いること。
- FR-45c: 一覧から**チャンクの手動追加**（§4.22）へ遷移できること。

### 4.9 例文一覧
- FR-46: チャンク一覧と**同一の上部フィルタ**（キーワード検索・自信なし・ファセット）を流用して絞り込めること。
- FR-47: 絞り込み済みチャンクの例文1〜5を**平坦に展開**し、英文＋日本語訳を一覧表示できること（空の例文は除外）。各行に出典のチャンク英語を併記すること。
- FR-48: 件数が多いため**ページング**（1ページ100件、チャンク一覧の FR-45b と同UI）で表示し、フィルタ変更時は先頭ページに戻すこと。
- FR-49: 各例文をタップで**例文カード**（§4.17）へ遷移でき（戻り先は例文一覧）、各例文を単発でTTS再生もできること。チャンク詳細へは例文カード内の導線から遷移する。

### 4.10 設定
- FR-50: TTSの音声・再生速度・自動読み上げの有無、および**音節カナ表示の有無**（FR-101）を設定できること。
- FR-51: 1セッションの出題枚数を設定できること。
- FR-52: 練習対象とするステータスを選択できること。
- FR-53: 設定は端末内に永続化すること。
- FR-54: 再生速度の調整は**英語の読み上げのみ**に適用し、日本語訳は常に等倍で再生すること。
- FR-55: チャット練習（§4.18）の設定として、**Gemini APIキー**（端末内にのみ保存する旨を明記）・**モデル**（**選択式**: 既定 `gemma-4-31b-it`〈Gemma 4〉/ `gemini-flash-latest`〈Gemini Flash〉/ その他は手入力。プリセット外の保存値は温存される）・**解説の言語**（日本語/英語）・**対象チャンク数**（2〜6）を設定でき、Google AI Studio（キー取得先）と表現ストック（§4.19）への導線を持つこと。モデルはチャット練習・教材化・AI長文で共通。

### 4.11 ホーム
- FR-60: 統計（今日の出題/新規/習得済み/今日やった/登録数/連続日数）を表示すること。
- FR-61: 各練習モード（瞬間英作文 / 文脈穴埋め / 長文音読 / チャット練習）へ遷移できること。
- FR-62: 未インポート時はインポートを促す導線を表示すること。
- FR-63: 統計の直下に**「今日の練習」**（§4.13）への最上位導線を、期日到来件数つきで表示すること。
- FR-64: **表現ストック（§4.19）への導線カード**をモード一覧に**常時**表示すること（教材化〈§4.20〉への恒久導線。ストックが0件でも表示し、1件以上のときは件数バッジを添えること）。

### 4.12 シラブル音節カナ表示
- FR-97: チャンク／例文の英文に、アメリカ英語ベースの**シラブル音節カタカナ**を任意で持たせ、英文の**下**に小さく表示できること。
- FR-98: 音節カナ内の**強勢（ストレス）**を強調表示できること（記法 `*…*`＝太字表示）。
- FR-99: 音節カナデータは**CSVの任意列**（チャンク=`音節`、例文=`音節1〜音節5`）で投入でき、未入力の場合は英文のみを表示すること（後方互換）。
- FR-100: 音節カナの表示はカード／詳細／練習画面（瞬間英作文・今日の練習・文脈穴埋め・チャンク詳細・長文音読・フレーズ再生）**および例文一覧**の行に対応すること。チャンク一覧の行は一覧性維持のため対象外とする。
- FR-101: 音節カナ表示の ON/OFF を設定で切り替えられ（既定ON）、端末内に永続化すること。

> 記法・作成手順・ChatGPT量産プロンプトは `docs/シラブル音節記法.md` に規定する。

### 4.16 読み上げハイライト（Word Spark）
- FR-140: 英文の読み上げ中、**現在発話中の単語**をマーカー風（背景色＋文字色）に強調表示できること。文字サイズは変えず、行の折り返しが揺れないこと。
- FR-141: 対象は**長文音読の本文**と**再現練習カード（ReproCard）の開示英文**（瞬間英作文・今日の練習・フレーズ再生の再現練習・「🔊もう一度」再生を含む）とする。日本語の読み上げは対象外。
- FR-142: 単語位置は TTS の boundary イベントに同期すること。イベントが発火しないエンジン（Android Chrome の Google TTS 等）では**推定タイミング**で単語を送ること（おおよその追従でよい）。推定の全体速度は**実際の発話時間の実測から自動較正**し（再生速度別に端末内へ永続化）、単語の配分は**音節数・強勢（機能語の弱形）・句読点ポーズ**を反映して英語のリズムに近づけること。
- FR-143: 読み上げの停止・終了・カード切替でハイライトを消すこと。
- FR-144: チャンク詳細・今日の練習の**例文一覧（5例文表示）**でも、各例文の🔊再生時に**その行だけ**ハイライトが進むこと（他の例文は表示のまま）。再生中に別の例文の🔊を押した場合はハイライトが移ること。

### 4.17 例文カード
- FR-150: 例文一覧でタップした例文を**1枚のカード**で練習できること。挙動は瞬間英作文の例文表示と同一
  （日本語訳表示・再生 → タッチ → 英文＋カナ表示・再生＋Word Spark ハイライト。「🔊もう一度」で聞き直し可）。
- FR-151: 「← 戻る / 進む →」で**絞り込み結果内の例文**を前後に移動できること。
- FR-152: 例文の出典（例文N・チャンク英語）を表示し、親チャンクの**チャンク詳細**（§4.14）への導線を持つこと。
- FR-153: 「← 一覧へ」で例文一覧に戻れること。

### 4.13 今日の練習（統合フロー）
- FR-110: SRSの期日到来カード（§4.7）を1つのセッションに集約し、カードごとの習熟度（Leitnerボックス）に応じた練習形式で自動出題できること。
- FR-111: 形式の出し分けは次のとおりとすること: 新規（未学習）=モデリング / box 0-1=再現練習 / box 2-3=瞬間英作文 / box 4以上=文脈穴埋め（穴埋めにできる例文がないチャンクは瞬間英作文）。
- FR-112: 形式はカード表示のたびに進捗から算出し、採点により box が変化した場合は同一セッション内の再出題でも形式が追従すること。
- FR-113: 採点は既存のSRS採点（FR-30〜31）に統合し、専用の進捗データを持たないこと。
- FR-114: 期日到来カードが0件のときは補充出題をせず、完了した旨を表示すること（既存の単独モードのランダム補充出題は従来どおり維持する）。
- FR-115: 現在の練習形式（モデリング/再現練習/瞬間英作文/文脈穴埋め）をカード上部にラベル表示すること。

### 4.14 チャンク詳細
- FR-120: チャンクの英語・音節カナ・日本語・メタ情報（Type/Category/Level/Priority）・**ステータス**・補足メモ（note）・例文一覧（英・カナ・和、個別TTS再生つき）を1画面で確認できること（CSV相当の全項目）。
- FR-121: 学習の記録（習熟度 box/5・「できた」「できなかった」回数・次回出題日）を表示すること。
- FR-122: 「覚えた」チェックを付け外しできること（FR-35と同一の状態）。
- FR-123: 画面下部から**連続再生プレイヤー**へ遷移でき、一覧から受け取った絞り込み結果（再生範囲）と戻り先をそのまま引き継ぐこと。
- FR-124: 一覧へ戻る導線を画面下部に持つこと（戻り先は起動元の一覧）。
- FR-125: **チャンク編集**（§4.22）への導線を持つこと。
- FR-126: **チャンクを削除**できること。削除前に確認を求め、学習の記録も一緒に消えることを明示すること。削除後は起動元の一覧へ戻ること。

### 4.15 文脈穴埋め
- FR-130: 例文中のチャンクを伏せ字にして表示し、文脈と日本語ヒント（チャンクの和訳）からチャンクを想起する練習ができること。
- FR-131: チャンクと例文のマッチングは**大文字小文字無視＋単語境界チェック**の部分一致のみとし、活用形の探索（ステミング）は行わないこと。アポストロフィの字種差（`'`/`’`）は吸収すること。
- FR-132: チャンクが見つかる例文を1つ以上持つフレーズだけを出題対象とし、1チャンクにつきマッチした例文から**ランダムに1つ**を出題すること（同一カードの表示中は固定）。
- FR-133: 開示後は例文全文（チャンク部分を強調表示）・音節カナ・TTS再生を提示し、3段階採点（FR-31）ができること。
- FR-134: 対象フレーズが0件のときはその旨を表示すること。
- FR-135: 「今日の練習」（§4.13）の box 4以上のカードにも同形式を適用すること。

### 4.18 チャット練習（AI英語コーチ）
- FR-160: AI英語コーチと英語のチャット会話を行い、蓄積したチャンクを実際に使う練習ができること。コーチは自然な会話を続けながら、誤りの訂正・より自然な表現の提案・アドバイスを行うこと。
- FR-161: バックエンドは **Gemini API の OpenAI 互換エンドポイント**（`chat/completions`）をブラウザから直接呼ぶ構成とし、**無料枠のみで運用できる**こと。APIキーは利用者が Google AI Studio で無料取得して設定画面から入力し、**端末内にのみ保存**すること（中継サーバを持たない）。
- FR-162: セッション開始時に**対象チャンク**（設定の個数。SRSの期日到来を弱い順に優先し、不足はランダム補充）を選び、コーチが会話に**自然に織り込む**こと（チャンクの列挙やクイズ形式にしない）。対象チャンクはチップ表示し、利用者の発話で使えたら点灯すること（クライアント側の正規化＋単語境界マッチ。`It takes ... to ~` のような穴あきチャンクにも対応。活用形は対象外＝C-11）。
- FR-163: コーチの英語は**基礎語彙・1文5〜6語程度の短文・シンプルな構造**とし、**日常・ビジネスで使い回しやすいフレーズ**を重視すること。1〜3文＋やさしい質問で会話を続けること。
- FR-164: 誤り・不自然な英語には `✏️` 行でより自然な言い方と短い解説を添えること。解説の言語（日本語/英語）は設定で切り替えられること（FR-55）。
- FR-165: 応答は**ストリーミング表示**すること。エラー（キー不正 / レート上限 / オフライン等）時は**会話履歴を保持したまま**日本語で理由を表示し、再送できること。一時的なサーバーエラー（5xx）は表示する前に自動で再試行すること（NFR-09）。
- FR-166: セッション終了時に日本語のまとめ（使えたチャンク数・具体的なアドバイス）を表示し、**✉️ メール（mailto でメーラー起動）と 📋 コピー**で共有できること。
- FR-167: **チャンク詳細・例文カードから直接起動**でき（「このチャンクで会話練習」「この例文で会話練習」）、そのチャンク（と例文の場面）を中心に会話が組まれること。
- FR-168: **下部メニューの「💬 チャット」タブ**から開けること。他ページへ移動しても**進行中の会話も終了後のまとめも保持**され、戻るとその状態から再開できること（新規セッションになるのはフォーカス指定起動時と「もう一度」のみ）。
- FR-169b: 会話画面は**入力バーを画面最下部に置く全画面レイアウト**とし、ソフトウェアキーボードが出てもAI側のトークが隠れないこと（キーボードの直上に入力バー、会話は最新まで自動スクロール。LINEのような入力感）。
- FR-169: 日本語IMEの変換確定Enterで誤送信しないこと。APIキー未設定時は設定画面への導線を表示すること。

### 4.19 表現ストック（追加候補チャンクの蓄積）
- FR-170: まとめの最後に、会話に出てきた（または役立ったはずの）**フレーズ集に未収載の基本表現**をコーチが2〜4件提案すること（**追加候補**）。デッキに既にある表現は表記ゆれ（大文字小文字・記号）を吸収して自動除外すること。
- FR-171: 追加候補に**チェックボックス**を設け、チェックした表現を端末内に**日付付きで蓄積**できること（チェック解除で取り消し。重複は自動排除）。
- FR-172: **表現ストック画面**で蓄積分を一覧（新しい順・追加日表示）・個別削除・全削除（確認あり）できること。
- FR-172b: チャット由来だけでなく、**自分で思いついた表現を手動でストックに追加**できること（英語必須・日本語任意〈空欄は教材化のAIが補完〉・重複は正規化キーで排除）。例文まで自分で書きたい場合に備え、チャンクの手動追加（FR-193）への導線も持つこと。
- FR-173: 蓄積分を**タブ区切りでコピー**（表計算・Notionのテーブルに直接貼り付け可能）または**メール送信**でき、数日分をPCでまとめて例文作成→Notionへ追加する運用も引き続き支援すること。
- FR-174: 導線として、まとめ画面のリンク（件数つき）と設定画面のリンクを持つこと。0件時はチャット練習への案内を表示すること。
- FR-175: 蓄積分を**CSVで共有/保存**できること（OS共有シートまたはダウンロード。そのCSVはアプリに再取り込みできる列名で出力する）。

### 4.20 教材化（表現ストック → AI補完 → デッキ追加）
- FR-176: 表現ストックの表現を選択し、AI が不足項目（**和訳・平易な例文1件・シラブル音節カナ・Type/Category/Level**）を補完した教材ドラフトを作成できること（「教材化する」ボタン）。
- FR-177: 生成は**ボタン起点のみ**とし、デッキ収載済みの表現は生成前に自動除外すること。既に和訳がある表現の和訳は生成させず入力値を使うこと。複数件は**バッチ処理**すること（無料枠の節約。NFR-08）。
- FR-178: **教材化＝即保存にしない**こと。プレビューで各フィールドを確認・編集・除外でき、確認後に**デッキへ直接追加**できること。追加した教材はすぐ練習（SRS・一覧・チャット練習）に現れること。
- FR-179: AI生成のシラブルカナは**ルールベースで機械検証**し（記号・強勢ペア・区切り位置・語数整合）、不合格は**「カナ要確認」フラグ付き**で保存・表示できること（保存自体は妨げない）。フラグはCSVの `カナ要確認` 列と往復し、後から人間・高性能モデルで監査できること。
- FR-180: デッキへ追加できた表現は表現ストックから自動的に取り除くこと。
- FR-181: 生成の失敗・APIエラー時は成功済み分を保持し、失敗した項目だけ再生成・再試行できること。生成中は進捗を表示し、中止できること。

### 4.21 AI長文作成
- FR-185: テーマ・難易度（Basic/Core/Advanced）・長さ（1段落/2段落）と、デッキから選んだ**チャンク3〜5個**を指定して、それらを自然に織り込んだ長文音読用の英文＋和訳を生成できること。
- FR-186: チャンク選択では**SRSの期日到来分を先頭に提示**し、検索で絞り込めること。
- FR-187: 生成結果はプレビューで**編集**でき、指定チャンクが本文に**含まれたかのチェック結果**を表示すること（含まれない場合も保存可・再生成可）。
- FR-188: 保存すると `Type='Long Reading'` のフレーズとしてデッキに追加され、**そのまま長文音読を始められる**こと（AI長文にシラブルカナは付けない）。

### 4.23 無料枠の残り目安表示
- FR-200: AI機能を使う画面（チャット練習・教材化プレビュー・AI長文作成・設定）に、Gemini API 無料枠の**残り回数の目安**を表示すること。残りを気にせず練習・生成に集中できるようにするための安心材料であり、正確な残数の保証はしない。
- FR-201: 残数は API から取得できない（C-14）ため、**このアプリから送ったリクエスト数を端末内で日次集計**し、既知モデルの無料枠 RPD（1日あたりリクエスト数）目安との差分で示すこと。集計日は無料枠のリセット（**太平洋時間の深夜**＝日本時間の夕方ごろ）に合わせ、目安である旨（AI Studio・他端末での消費は含まれない、上限は変更されうる）を設定画面に明記すること。

### 4.24 Androidネイティブアプリ
- FR-210: 同一コードベースから **Androidネイティブアプリ（APK）** を提供すること。CSV取込・カナ表示・SRS・AI機能を含む全機能がWeb版と同等に動作すること。読み上げはWebViewの制約（speechSynthesis非搭載＝C-16）を吸収するため、**Androidシステム TTS（Chromeと同じエンジン・声）** をアダプタ経由で用いること。
- FR-211: ネイティブアプリでは、連続再生・長文音読が**画面オフでも継続する**こと（mediaPlayback型フォアグラウンドサービス＋部分ウェイクロック。設定不要の常時有効）。再生中は通知に再生中の教材を表示し、停止で消えること。通知権限が拒否されても再生は継続すること。
- FR-212: APKは**GitHub ActionsでビルドしReleaseに自動添付**すること（ローカルにAndroid Studio不要）。署名は永続キーストアで行い、versionCodeは`package.json`のversionから単調増加で導出し、**常に上書きインストールが成立**すること。
- FR-213: アプリ内（設定→アプリについて）にバージョン表示と最新APKへの導線を持つこと。
- FR-214: ネイティブアプリでは不要な回避策のUIを出さないこと（🌙暗くして再生・実験的キープアライブ設定はWeb限定表示）。
- FR-215: **進捗を含むフルバックアップ**（教材＋SRS進捗＋ストリークのJSON）のエクスポート/インポートができること（PWA→アプリのデータ移行・機種変更用）。APIキーは含めないこと。復元は全置換とし、確認を挟むこと。

### 4.22 チャンク編集・手動追加
- FR-190: デッキ内のチャンクの**全フィールド**（英語・日本語訳・音節カナ・Type/Category/Level/Priority/ステータス/Note・例文最大5〈英・和・カナ〉）をアプリ内で編集できること。英語・日本語訳は必須とすること。
- FR-191: 編集で英語（Chunk）を変更しても、**IDと学習の記録（SRS進捗）・登録日時を維持**すること。
- FR-192: カナ欄は編集中にルールベース検証（FR-179）の結果を表示し、保存時に**「カナ要確認」フラグを再計算**すること（正しいカナに修正して保存すれば解除される）。
- FR-193: チャンクを**手動で新規追加**できること（一覧の「＋ 追加」から。既定値: Type=Chunk / Level=Core / ステータス=未着手）。追加分はアプリ内追加の教材としてマージ取り込み（FR-06）で保持されること。
- FR-194: 保存時に**同一英文の重複**（大文字小文字・記号差を正規化して比較）を検出し、重複時は保存せず既存チャンクへの導線を示すこと。編集時は自分自身を除いて判定すること。

## 5. 非機能要件

| 区分 | 要件 |
|---|---|
| NFR-01 オフライン | 初回読み込み後はネットワークなしで動作すること（PWA / Service Worker）。**例外: AI機能（チャット練習〈§4.18〉・教材化〈§4.20〉・AI長文〈§4.21〉）はオンライン必須**（オフライン時はその旨を表示） |
| NFR-02 プライバシー | 学習データ・フレーズは端末内のみに保存し、外部送信しないこと。**例外: AI機能では会話文・対象チャンク・教材化対象の表現（英語・和訳）が Gemini API へ送信される**（利用者が明示的に開始した場合のみ） |
| NFR-03 セキュリティ | クライアントにNotion APIキー等の秘密情報を持たせないこと。**チャット練習の Gemini APIキーは利用者自身が入力するものとし、端末内（localStorage）にのみ保存、Google のエンドポイント以外へ送信しない**こと |
| NFR-04 操作性 | スマホ縦持ちでの片手操作を前提としたモバイルファーストUI。各練習画面の離脱導線（「✕ やめる」「← 一覧へ」）は親指で届く画面**下部**に配置し、上部ヘッダーはタイトルと進捗の表示に限ること |
| NFR-05 インストール性 | ホーム画面に追加でき、スタンドアロン表示で起動できること |
| NFR-06 保守性 | 機能領域（SRS/保存/TTS/取り込み/画面）を分離した構成とすること |
| NFR-07 互換性 | 進捗はフレーズIDをキーに保持し、再取り込みで失われないこと |
| NFR-08 API利用の節度 | AI生成は無料枠で運用できるよう抑制すること: 明示的なボタン起点のみ生成 / 不足項目のみ生成 / 複数件はバッチ / 例文は初期1件 / リトライは1回まで |
| NFR-09 AI通信の信頼性 | 無料枠の混雑等で散発する**一時的なサーバーエラー（5xx）は、バックオフを挟んで自動再試行**すること（最大2回・本文受信前のみ・中止可能）。**429（レート上限）は自動再試行しない**こと（上限消費を悪化させないため）。自動再試行で回復しない場合も、成功済みの結果を失わずに手動で再試行できること（FR-165・FR-181） |

## 6. 制約・前提

- C-01: 発音の自動採点（音声認識スコアリング）は本バージョンの対象外。採点は利用者の自己申告とする。
- C-02: TTSの音声品質・声の種類は端末の対応に依存する。
- C-03: iOS Safariでは、TTSの初回再生にユーザー操作（ボタンタップ）が必要。
- C-04: Notionとのリアルタイム自動同期は行わない。更新は利用者による再エクスポート＆再インポートで反映する。
- C-05: CSVは `ID` 列をそのまま id に採用する。`ID` 列が無い旧データや `.md` のテーブルでは英文から生成した安定IDで代替する（`.md` ページはファイル名末尾のNotionページIDを使用）。
- C-08: 例文の日本語訳は元データ（Notion/CSV）側で用意し、`日本語訳{n}` 列として保持する。空欄の場合、再現練習や和訳読み上げではその項目の和訳がスキップされる。
- C-06: 【Web/PWA限定】**ブラウザのTTS（Web Speech API）は画面消灯・タブ非表示で再生が停止する仕様**であり、確実な回避策がない。
  Web版の連続再生は画面点灯（Screen Wake Lock）前提＋実験的キープアライブ（FR-202）。
  **確実な画面オフ再生はネイティブアプリ（§4.24）が提供**する。
- C-07: **「暗くして再生」はバックライト自体を消す機能ではない**（Webに明るさ制御APIが無い）。
  画面を黒く塗るのみで、有機ELでは実質消灯に近く、液晶では手動で明るさを下げると効果的。
- C-09: 読み上げハイライト（§4.16）の単語同期精度は端末依存。boundary イベントが発火しないエンジン
  （Android Chrome の Google TTS 等）では文字数×再生速度からの**推定**となり、実際の発音と多少ずれることがある。
- C-10: AI機能（チャット練習〈§4.18〉・教材化〈§4.20〉・AI長文〈§4.21〉）はネットワークと利用者自身の Gemini APIキーが必要。無料枠の**レート制限（429）**に達した場合は時間を置く必要がある。応答の品質・可用性・無料枠の条件は Google 側の提供状況に依存する。
- C-11: チャンク使用検出（FR-162）は正規化＋単語境界の一致のみで、**活用形は検出しない**（例: チャンク `come down with` に対し発話 `came down with` は不一致）。
- C-12: Gemma 系モデルには応答冒頭に内部思考タグ（`<thought>…</thought>`）を出力する・`system` ロールを拒否する等の癖があり、クライアント側で吸収する（表示・履歴送信前の除去、user メッセージへの前置リトライ）。
- C-13: AI生成（教材化・AI長文）の訳・例文・カナは**下書き品質**であり、誤りを含み得る。カナの機械検証（FR-179）は書式の検査であって発音的な正しさを保証しない。プレビューでの確認と、要確認フラグの定期監査を前提とする。
- C-14: Gemini API は**残クォータを取得するAPIを提供していない**。無料枠の残り表示（§4.23）は端末内カウントによる目安であり、AI Studio や他端末での消費・Google 側の上限変更は反映できない。
- C-15: 実験的バックグラウンド再生（FR-202）は、ブラウザが「音声を再生中のタブ」を凍結・タイマー抑制の
  対象外にする挙動に依存する**非公式のハック**であり、ブラウザの更新で無効化され得る。iOS Safari では効果がない。
  効かない端末では「暗くして再生」（FR-86）かネイティブアプリを使う。
- C-16: **Android WebView には speechSynthesis が存在しない**（Chromium は対応予定なし）。ネイティブアプリの
  読み上げはシステムTTS直結のアダプタ（FR-210）で実現しており、Web Speech API は使っていない。
- C-17: APKの**署名キーを紛失すると上書きインストールが不可能**になる（アンインストール＝端末データ消失が必要。
  フルバックアップ〈FR-215〉からの復元は可能）。鍵はリポジトリ外（`Documents/my-phrases-signing/`）で保管し、
  複製をクラウド等に保持する運用とする。ネイティブアプリの初回インストール時はデータが空であり、
  移行はフルバックアップで行う（APIキーのみ再入力）。

## 7. 対象外（本バージョンのスコープ外）

- 音声認識による発音スコアリング
- 複数ユーザー/アカウント、クラウド同期、端末間同期（表現ストック〈§4.19〉も端末内のみ。PCへの受け渡しはコピー/メール/CSV共有で行う）
- ~~既存フレーズの汎用的なアプリ内編集UI~~（**v0.9.0 で対象内**: 編集・削除・手動追加〈§4.22〉。一括編集・スプレッドシート型の表編集UIは引き続き対象外で、CSVエクスポート〈FR-06b〉で行う）
- 学習リマインダー通知（プッシュ通知）
- フレーズ集全体の一括自動添削・全件一括のAI再生成（**教材化・AI長文・チャット練習内の ✏️ 訂正・表現提案〈§4.18〜4.21〉は対象内**）
- チャット練習の結果（使えたチャンク）の SRS への自動反映
- 音声入出力によるAI会話（チャット練習はテキストのみ）
- ~~保証のある画面オフ音声再生~~（**v1.0.0 で対象内**: ネイティブアプリ〈§4.24〉が正式サポート。Web/PWA側の保証は引き続き対象外）
- Google Play ストアでの配布・iOS アプリ（APKの直接配布のみ。単一ユーザーのため）
