# My Phrases 要件定義書

- 文書バージョン: 1.0
- 作成日: 2026-06-17
- 対象システム: My Phrases（英語フレーズ練習PWA）

---

## 1. 背景・目的

利用者はNotionのデータベース「🔠 フレーズ集」に、日常英語フレーズと日本語訳をほぼ毎日蓄積している。
しかしNotionは情報を「貯める」用途には向くが、「反復練習する」用途には向かない。

本システムは、蓄積した英語フレーズ資産を取り込み、スマートフォンで手軽に
**瞬間英作文**（日本語→英語を即座に生成）と **発音練習**（お手本再生→発話→自己採点）を
行えるようにすることを目的とする。

### ゴール
- 通勤・隙間時間にスマホで反復練習ができる
- Notionの蓄積を最小手間でアプリに反映できる
- 学習の進捗が記録され、復習すべきフレーズが自動で提示される

---

## 2. 利用者・利用環境

| 項目 | 内容 |
|---|---|
| 主な利用者 | フレーズDBの所有者本人（英語学習者） |
| 端末 | スマートフォン（iOS Safari / Android Chrome）中心。PCブラウザも可 |
| 形態 | PWA（ホーム画面に追加してアプリのように使用） |
| ネットワーク | 初回読み込み後は**オフラインで動作**すること |
| 言語 | UIは日本語、学習対象は英語 |

---

## 3. 用語定義

| 用語 | 定義 |
|---|---|
| フレーズ | 学習単位。英語文（en）・日本語訳（ja）・例文（example）・ステータスを持つ |
| 瞬間英作文 | 日本語訳を見て、英語を即座に口頭/頭の中で生成する練習 |
| 発音練習 | 英語のお手本音声を聞き、声に出して真似る練習 |
| SRS | 間隔反復学習（Spaced Repetition System）。Leitnerボックス方式 |
| インポート | Notionのエクスポートファイルをアプリに読み込むこと |
| サンプルデータ | 未インポート時に表示される初期内蔵データ |

---

## 4. 機能要件

### 4.1 フレーズ取り込み（インポート）
- FR-01: NotionからエクスポートしたファイルをアプリのUIから取り込めること。
- FR-02: 取り込み対応形式は **`.zip`（Markdown & CSV一括）/ `.csv` / `.md`** とする。
- FR-03: `.zip` は解凍せずそのまま取り込めること（アプリ内で解凍）。
- FR-04: `.md` は複数ファイルの同時選択に対応すること。
- FR-05: 取り込んだデータは端末内に永続保存し、再起動・オフラインでも利用できること。
- FR-06: 再取り込み時は全件を入れ替える（Notion側の削除を反映）。ただし学習進捗は保持すること。
- FR-07: 取り込みデータを消去し、サンプル表示に戻せること。
- FR-08: APIキーやサーバ連携、ターミナル操作を必須としないこと。

### 4.2 瞬間英作文
- FR-10: 日本語訳を提示し、利用者の操作で英語の解答を表示できること。
- FR-11: 解答表示時に英語をTTSで読み上げられること（自動/手動）。
- FR-12: 例文があれば任意で表示できること。
- FR-13: 自己採点を3段階（できた / あいまい / できなかった）で記録できること。
- FR-14: 「できた」以外はそのセッション内で再出題されること。

### 4.3 発音練習
- FR-20: 英語フレーズとお手本音声（TTS）を提示すること。
- FR-21: 出題時にお手本を自動再生し、手動で再生し直せること。
- FR-22: 日本語訳を参考として併記すること。
- FR-23: 自己採点を2段階（言えた / もう一度）で記録できること。

### 4.4 学習管理（SRS）
- FR-30: フレーズごとに学習状態（ボックス・次回出題日・正誤回数・最終学習日）を保持すること。
- FR-31: 採点結果に応じて次回出題日を自動調整すること。
- FR-32: 「今日の出題」は出題対象（期限到来＋新規）から、設定枚数を上限に提示すること。
- FR-33: 連続学習日数（ストリーク）を記録・表示すること。
- FR-34: 学習進捗を全消去できること。

### 4.5 一覧・検索
- FR-40: 全フレーズを一覧表示できること。
- FR-41: 英語/日本語のキーワードで絞り込めること。
- FR-42: ステータス（未着手/進行中/完了）で絞り込めること。
- FR-43: 各フレーズをタップでTTS再生できること。
- FR-44: 習得済みフレーズを判別表示すること。

### 4.6 設定
- FR-50: TTSの音声・再生速度・自動読み上げの有無を設定できること。
- FR-51: 1セッションの出題枚数を設定できること。
- FR-52: 練習対象とするステータスを選択できること。
- FR-53: 設定は端末内に永続化すること。

### 4.7 ホーム
- FR-60: 統計（今日の出題/新規/習得済み/今日やった/登録数/連続日数）を表示すること。
- FR-61: 各練習モードへ遷移できること。
- FR-62: 未インポート時はインポートを促す導線を表示すること。

---

## 5. 非機能要件

| 区分 | 要件 |
|---|---|
| NFR-01 オフライン | 初回読み込み後はネットワークなしで全機能が動作すること（PWA / Service Worker） |
| NFR-02 プライバシー | 学習データ・フレーズは端末内のみに保存し、外部送信しないこと |
| NFR-03 セキュリティ | クライアントにNotion APIキー等の秘密情報を持たせないこと |
| NFR-04 操作性 | スマホ縦持ちでの片手操作を前提としたモバイルファーストUI |
| NFR-05 インストール性 | ホーム画面に追加でき、スタンドアロン表示で起動できること |
| NFR-06 保守性 | 機能領域（SRS/保存/TTS/取り込み/画面）を分離した構成とすること |
| NFR-07 互換性 | 進捗はフレーズIDをキーに保持し、再取り込みで失われないこと |

---

## 6. 制約・前提

- C-01: 発音の自動採点（音声認識スコアリング）は本バージョンの対象外。採点は利用者の自己申告とする。
- C-02: TTSの音声品質・声の種類は端末の対応に依存する。
- C-03: iOS Safariでは、TTSの初回再生にユーザー操作（ボタンタップ）が必要。
- C-04: Notionとのリアルタイム自動同期は行わない。更新は利用者による再エクスポート＆再インポートで反映する。
- C-05: `.csv` 取り込みではNotionページIDが含まれないため、英文から生成した安定IDで代替する。

---

## 7. 対象外（本バージョンのスコープ外）

- 音声認識による発音スコアリング
- 複数ユーザー/アカウント、クラウド同期、端末間同期
- フレーズのアプリ内編集・追加（編集はNotion側で行う）
- 学習リマインダー通知（プッシュ通知）
- AIによる例文生成・添削
