# シラブル音節カナ ＋ 強勢 記法仕様

My Phrases の英文（チャンク／例文）に添える、**アメリカ英語ベースのシラブル（音節）カタカナ表記**と
**強勢（ストレス）**の作り方をまとめる。CSV の `音節` / `音節1〜音節5` 列に、この記法で文字列を入れると、
アプリが英文の下に小さく表示し、強勢の音節を太字＋濃色で描画する（[src/components/KanaLine.tsx](../src/components/KanaLine.tsx)）。

データは ChatGPT などで量産することを想定し、誰が作っても同じ書式になるよう記号を固定する。

---

## 1. 記号一覧

| 記号 | 意味 | 例 |
|---|---|---|
| `・` | 同じ単語内の**音節の区切り** | `プラク・ティス`（practice） |
| 半角スペース | **単語の区切り** | `キープ ゴウ・イング`（keep going） |
| `‿` | **リンキング**（前の子音が次の語の頭母音にくっつく） | `フォウ・カ‿ソン`（focus on） |
| `( )` | **ほぼ聞こえない／飲み込まれる音**（語末の t/d など） | `ナッ(ト)`（not）, `クッ(ド)`（could） |
| `*…*` | **強勢（ストレス）**。囲んだ部分を太字＋濃色で表示 | `*ス・ティル*`, `ビ・*コーズ*` |

- `*` は半角アスタリスク。**開き/閉じをペア**で使う（`*ティ*`）。1文に複数置いてよい。
- `*` の中に `・` や `‿` を含めてもよい（例: `*ス・ティル*`）。
- 表示時に `*` 自体は消える（区切り記号として消費される）。

---

## 2. 作成手順（アメリカ英語）

1. **単語ごとに音節へ分ける**（ev・ery → エヴ・リ、prob・lem → プラ・ブレム）。
2. 各音節を**アメリカ発音のカタカナ**にする。
   - `th`（this/that）＝ ザ/ジ/ゼ（有声）、`v`＝ ヴ、`l`＝ ル/ラ行、`r`＝ ア/ャ など。完全一致は不要、近い音で可。
3. **リンキング・脱落・弱化**を反映する（“読まれる音の流れ”にする）。
   - リンキング：子音＋次の語の母音は `‿` でつなぐ（role is → `ロウ・リズ`、focus on → `フォウ・カ‿ソン`）。
   - 語末の t/d はよく飲み込まれる → `( )`（not → `ナッ(ト)`、could → `クッ(ド)`）。
   - 機能語は弱化：to → `タ`、can → `ク(ン)`、them → `(ゼ)ム`、and → `エン(ド)`、of → `ァヴ`。
   - 母音間の t は軽い「ら行／だ行」風（フラップ）：better → `ベ・ラ`、getting → `ゲ・リン(グ)`、noticed → `ノウ・リス(ト)`。
4. **強勢（内容語）を `*…*` で囲む**。
   - 強めるのは意味の核になる語（名詞・動詞・形容詞・副詞）。`I / to / the / a / is / and` などの機能語は基本くくらない。
   - 1単語に主強勢は1つ。多音節語はアクセント音節だけを囲む（important → `イム・*ポー*・タン(ト)`）。

> 補足：カナで表せない音（l, th, v など）は近似。発音の細部より、**音節の区切り・つながり・どこを強く言うか**が伝われば十分。

## 3. CSV 列仕様

- 列名（アプリは**列名で判定**するので順序は自由だが、運用は下記の並びを推奨）:
  - チャンク用: `音節`（`Chunk` の音節カナ）
  - 例文用: `音節1` … `音節5`（各 `Example{n}` の音節カナ）
- 推奨の並び（このリポジトリで生成した形）:
  ```
  ID, Type, Category, Level, Priority, Chunk, 日本語, 音節,
  Example1, 日本語訳1, 音節1, …, Example5, 日本語訳5, 音節5, Note
  ```
  ＝ チャンクは「英・和・音節」、各例文も「例文・和訳・音節」の順。
- **空欄可**。音節列が空ならアプリは英文だけを表示する（後方互換）。
- 強勢は `*…*`。フォールバック列名も使える（`Chunk_Kana`/`Syllable`、`Example{n}_Kana`/`カナ{n}` 等。[src/lib/import.ts](../src/lib/import.ts) 参照）。

|---|---|
| still | `*ス・ティル*` |
| I still have a headache. | `アイ ス・*ティル* ハ・ヴァ *ヘッ*・デイク` |

## 5. ChatGPT への指示プロンプト

英文のリスト（または CSV の英語列）を貼り付けて使う。出力をそのまま `音節` 列に貼れる。

```text
あなたはアメリカ英語の発音コーチです。
これから渡す英文を、日本人学習者向けに「シラブル（音節）カタカナ＋強勢」に変換してください。

# 記法（厳守）
- 単語内の音節の区切り = 「・」（中黒）
- 単語の区切り = 半角スペース
- リンキング（子音が次の語の頭母音につながる）= 「‿」
- ほぼ聞こえない/飲み込まれる音（語末の t,d など）= 丸かっこ（例: ナッ(ト)、クッ(ド)）
- 強勢（ストレス）の音節 = 半角アスタリスクで囲む（例: *ス・ティル*、ビ・*コーズ*）。開き閉じをペアで。

# 方針
- アメリカ発音をベース。実際に「つながって聞こえる音の流れ」を表す（リンキング・脱落・弱化・母音間 t のフラップ=ら行/だ行）。
- 機能語（to, the, a, of, and, can, them など）は弱化。基本は強勢で囲まない。
- 強めるのは意味の核（名詞・動詞・形容詞・副詞）。多音節語はアクセント音節だけ囲む。
- カナで表せない音（l, th, v, r）は近い音で近似してよい。完璧な音より、音節の区切り・つながり・強勢が伝わることを優先。
- 出力は変換結果の文字列のみ。説明や表は不要。1英文につき1行。

# 例
入力: still
出力: *ス・ティル*
入力: I still have a headache.
出力: アイ ス・*ティル* ハ・ヴァ *ヘッ*・デイク
入力: focus on
出力: *フォウ*・カ‿*ソン*
入力: Even though it is hard, I want to keep going.
出力: *イー*・ヴン・*ゾウ* イ・*ティズ* *ハー(ド)* アイ *ワナ* *キープ* *ゴウ*・イング

# 入力
（ここに英文を1行ずつ貼る）
```

CSV をまとめて処理させたい場合は、最後の指示を次に差し替える:

```text
# 入力（CSV）
次の CSV の Chunk と Example1〜5 を、それぞれ上記記法に変換し、
ID と、音節・音節1〜音節5 列だけを持つ CSV にして返してください（ヘッダー: ID,音節,音節1,音節2,音節3,音節4,音節5）。
空の例文は空欄のままにすること。
（ここに CSV を貼る）
```
