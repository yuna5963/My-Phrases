## 1. システム構成

クライアント完結型のPWA。サーバ・バックエンドを持たない。

```
[ブラウザ / PWA]
  ├─ UI（React + React Router(HashRouter)）
  ├─ 状態管理（Zustand: 設定 / デッキ）
  ├─ ロジック（SRS / セッション / TTS / インポート解析）
  └─ 永続化（IndexedDB: フレーズ・進捗・メタ / localStorage: 設定）
        ▲
        │ 取り込み（手動・1回限り）
[Notionエクスポート（.zip / .csv / .md）]
```

### 1.1 技術スタック

| 領域 | 採用技術 |
|---|---|
| 言語 | TypeScript |
| UI | React 18 |
| ビルド | Vite 5 |
| ルーティング | react-router-dom（HashRouter） |
| スタイル | Tailwind CSS（darkMode: media） |
| 状態管理 | Zustand（設定はpersistでlocalStorage保存） |
| 永続化 | IndexedDB（idb ラッパ） |
| ZIP解凍 | fflate（ブラウザ内・オフライン） |
| 音声 | Web Speech API（SpeechSynthesis） |
| PWA | vite-plugin-pwa（Workbox / Service Worker） |

## 3. データモデル

### 3.1 型定義（`src/types.ts`）

```ts
interface Phrase {
  id: string          // 安定キー（md:ページID / csv:英文ハッシュ / sample:sample-NNN）
  en: string          // 英語フレーズ
  ja: string          // 日本語訳
  example: string     // 例文（空可）
  status: string      // '未着手' | '進行中' | '完了'
  createdTime: string // ISO日時（無い場合は ''）
}

interface Progress {
  id: string
  box: number         // Leitnerボックス 0..5
  due: string         // 次回出題日 'YYYY-MM-DD'
  correct: number
  wrong: number
  lastSeen: string    // 最終学習日時 ISO（未学習は ''）
}

type Grade = 'good' | 'vague' | 'bad'
```

### 3.2 永続化（IndexedDB: `my-phrases`, version 2）

| ストア | キー | 値 | 用途 |
|---|---|---|---|
| `phrases` | `id`（keyPath） | Phrase | 取り込んだフレーズ（空=サンプル使用） |
| `progress` | `id`（keyPath） | Progress | 学習進捗（フレーズと独立に保持） |
| `meta` | 任意キー | 任意 | `streak`（連続日数）, `lastStudyDate` |

- 設定（音声/速度/自動再生/出題数/対象ステータス）は localStorage（キー: `my-phrases-settings`）。
- **進捗とフレーズは別ストア**。再インポートでフレーズを入れ替えても、同一IDの進捗は維持される。

## 4. SRS仕様（`src/lib/srs.ts`）

Leitnerボックス方式。ボックス 0..5（`MAX_BOX = 5`）。

### 4.1 出題間隔（日）

| box | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| INTERVALS | 0 | 1 | 3 | 7 | 16 | 45 |

### 4.2 採点による遷移（`applyGrade`）

| 採点 | box変化 | 次回出題日（due） | 補足 |
|---|---|---|---|
| good（できた/言えた） | `min(box+1, 5)` | 今日 + INTERVALS[新box] | correct++ |
| vague（あいまい/もう一度） | 変更なし | 今日 + 1日 | 早期に再復習 |
| bad（できなかった） | 0 にリセット | 今日（= +0日） | wrong++ |

- `isDue(p)`: `p.due <= 今日`
- `isMastered(p)`: `box >= 5`
- `isNew(p)`: `lastSeen === ''`
- 日付は端末ローカル時刻基準の `YYYY-MM-DD`。

### 4.3 ストリーク（`useDeck.bumpStreak`）

- 採点時、`lastStudyDate` が当日でなければ更新。
- 前日に学習していれば `streak + 1`、そうでなければ `1` にリセット。

## 5. 出題・統計仕様（`src/lib/session.ts`）

### 5.1 今日の出題（`buildSession`）
1. 対象 = 設定の `includeStatuses` に合致し、`isDue` かつ `!isMastered` のフレーズ。
2. 並び順 = box昇順（弱いカード優先）→ due昇順。
3. 先頭から `sessionSize` 枚を採用。
4. 0枚の場合は、対象ステータスのフレーズをシャッフルして `sessionSize` 枚（自由練習フォールバック、`useSession` 側）。

### 5.2 統計（`computeStats`）

| 指標 | 定義 |
|---|---|
| due（今日の出題） | 対象かつ `isDue` かつ未習得 の件数 |
| newCount（新規） | `isNew` の件数 |
| mastered（習得済み） | `isMastered` の件数 |
| studiedToday（今日やった） | `lastSeen` の日付が当日 の件数 |
| total（登録） | 対象ステータスの総数 |

## 6. インポート仕様（`src/lib/import.ts`）

入口: `parsePhrasesFromFiles(files: File[]): Promise<Phrase[]>`

### 6.1 ファイル種別の処理

| 入力 | 処理 |
|---|---|
| `.zip` | fflate `unzipSync` で解凍し、`.md/.markdown/.txt/.csv` エントリのみ処理 |
| `.csv` | `fromCsv`（RFC4180準拠の簡易パーサ） |
| `.md/.markdown/.txt` | テーブル形式を優先（`fromMarkdownTable`）、無ければページ形式（`fromMarkdownPage`） |

複数ファイル・複数エントリの結果は **IDで重複排除**（後勝ち）。`en` と `ja` の両方が空の行は除外。

### 6.2 列・プロパティのマッピング

| Phrase | Notionプロパティ名 |
|---|---|
| en | `フレーズ`（CSVヘッダ / MD H1） |
| ja | `日本語訳` |
| example | `使用例（例文）` |
| status | `ステータス`（無ければ `未着手`） |

### 6.3 ID採番（`stableId` / `idFromFilename`）
- `.md`: ファイル名末尾の32桁hex（NotionページID）を使用。無ければ英文ハッシュ。
- `.csv` / hexなし: 英文の FNV-1a 32bit ハッシュ → `p_<hex>`。
- 同一英文なら常に同一IDとなり、再取り込み時に進捗が維持される。

### 6.4 保存（`useDeck.importFiles`）
1. `parsePhrasesFromFiles` で解析。0件なら例外（UIにエラー表示）。
2. `replacePhrases`（`phrases` ストアを clear → 全件 put、単一トランザクション）。
3. `load()` を再実行し、`source = 'imported'` で画面更新。

## 7. 状態管理仕様

### 7.1 デッキ（`src/store/useDeck.ts`）

| 状態 | 内容 |
|---|---|
| `phrases` | 表示中フレーズ（createdTime降順ソート） |
| `progress` | id→Progress のマップ |
| `streak` | 連続学習日数 |
| `source` | `'imported'` / `'sample'` |
| `loaded` / `error` | 読み込み状態 |

| アクション | 振る舞い |
|---|---|
| `load()` | 取り込み済みがあればそれを、無ければ `public/data/phrases.json` を読み、進捗とマージ |
| `grade(id, g)` | SRS更新→`progress`ストア保存→ストリーク更新 |
| `importFiles(files)` | インポート（§6.4）、取り込み件数を返す |
| `clearImported()` | `phrases`ストアを消去しサンプルへ戻す |
| `reset()` | 進捗・ストリークを全消去 |

### 7.2 設定（`src/store/useSettings.ts`、persist）

| キー | 既定値 | 説明 |
|---|---|---|
| `voiceURI` | null（端末既定） | TTS音声 |
| `rate` | 0.9 | 再生速度（0.5〜1.2） |
| `autoPlay` | true | 解答時/出題時の自動読み上げ |
| `sessionSize` | 20 | 1セッション出題枚数（5〜50） |
| `includeStatuses` | 未着手/進行中/完了 | 練習対象ステータス |

## 8. 画面仕様

ルーティングは HashRouter（`#/`, `#/compose`, `#/pronounce`, `#/browse`, `#/settings`）。
下部ナビ（ホーム/一覧/設定）は表示。**練習中（compose / pronounce）は下部ナビを非表示**にし、
固定ナビが操作ボタンと重ならないようにする。

### 8.1 ホーム（`Home.tsx`）
- 統計カード（§5.2）とストリーク表示。
- 「⚡瞬間英作文」「🗣️発音練習」への遷移ボタン。
- `source === 'sample'` のときインポート導線バナーを表示。
- 今日の出題が0のとき完了メッセージを表示。

### 8.2 瞬間英作文（`Compose.tsx` + `useSession`）
1. 日本語訳を大きく表示。
2. 「答えを見る」で英語・再生ボタン・例文（任意）を表示。`autoPlay` なら英語を自動再生。
3. 3段階採点ボタン（✕/🔺/⭕）。`good` 以外はキュー末尾へ再投入。
4. キュー終了で結果サマリ（できた/あいまい/できなかった件数、ホーム/もう一度）。

### 8.3 発音練習（`Pronounce.tsx` + `useSession`）
1. 英語・日本語訳を表示し、出題時にお手本を自動再生。
2. 「もう一度聞く」で再生。
3. 2段階採点（🔁もう一度=vague / ✅言えた=good）。

### 8.4 一覧（`Browse.tsx`）
- 検索（en/ja部分一致）、ステータスチップ絞り込み、件数表示。
- 各項目: 英語・日本語・習得済みマーク・TTS再生ボタン。

### 8.5 設定（`Settings.tsx`）
- 音声: 読み上げ音声選択 / 再生速度（変更時にテスト発話）/ 自動読み上げ。
- セッション: 出題枚数 / 対象ステータス。
- フレーズの取り込み: 現在データ表示（サンプル|取り込み済み / 件数）、手順説明、ファイル選択（`.zip,.csv,.md,.markdown,.txt`・複数可）、結果メッセージ、取り込み消去。
- データ: 学習進捗リセット（confirm確認あり）。

## 9. 音声仕様（`src/lib/tts.ts`）

- `loadVoices()`: `getVoices()`／`onvoiceschanged`／500msフォールバックで音声一覧を取得。
- `getEnglishVoices()`: `lang` が `en` で始まる音声に限定。
- `speak(text, {voiceURI, rate})`: 既存発話を `cancel` 後に発話。`lang` 既定 `en-US`。
- iOS Safari対策: 再生は必ずボタン操作起点（PlayButton / 出題時のユーザー遷移）で発火。

## 10. PWA / ビルド・配信仕様

- `vite.config.ts` の VitePWA（`registerType: autoUpdate`）でSW・manifestを生成。
- `phrases.json` は StaleWhileRevalidate でキャッシュ。アプリシェルはプリキャッシュ。
- `base: './'` によりサブパス配信に対応（GitHub Pages等）。
- アイコンは `public/icons/icon.svg`（`any` / `maskable`）。
- スクリプト:
  - `npm run dev` 開発サーバ
  - `npm run build` 型チェック（`tsc --noEmit`）＋本番ビルド（`dist/`）
  - `npm run preview` 本番プレビュー

## 11. 既知の制約・注意

- 発音採点は自己申告（音声認識は未実装）。
- TTSの声・品質は端末依存。
- `.csv` 取り込みはページIDを持たないため英文ハッシュIDを使用（英文変更で別フレーズ扱い）。
- インポートは全件置換方式（部分追記ではない）。
