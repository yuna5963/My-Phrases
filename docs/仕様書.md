## 1. システム構成

クライアント完結型のPWA。サーバ・バックエンドを持たない。

```
[ブラウザ / PWA]
  ├─ UI（React + React Router(HashRouter)）
  ├─ 状態管理（Zustand: 設定 / デッキ）
  ├─ ロジック（SRS / セッション / TTS / インポート解析 / 文数判定 / Wake Lock）
  └─ 永続化（IndexedDB: フレーズ・進捗・メタ / localStorage: 設定）
        ▲
        │ 取り込み（手動・1回限り）
[Notionエクスポート（.zip / .csv / .md）]
```

### 1.1 技術スタック

| 領域 | 採用技術 |
|---|---|
| 言語 | TypeScript |
| UI | React 18 |
| ビルド | Vite 5 |
| ルーティング | react-router-dom（HashRouter） |
| スタイル | Tailwind CSS（darkMode: media） |
| 状態管理 | Zustand（設定はpersistでlocalStorage保存） |
| 永続化 | IndexedDB（idb ラッパ） |
| ZIP解凍 | fflate（ブラウザ内・オフライン） |
| 音声 | Web Speech API（SpeechSynthesis） |
| スリープ抑止 | Screen Wake Lock API（連続再生中のみ） |
| PWA | vite-plugin-pwa（Workbox / Service Worker） |

## 3. データモデル

### 3.1 型定義（`src/types.ts`）

```ts
interface Phrase {
  id: string          // 安定キー（md:ページID / csv:英文ハッシュ / sample:sample-NNN）
  en: string          // 英語フレーズ
  ja: string          // 日本語訳
  example: string     // 例文（空可）
  status: string      // '未着手' | '進行中' | '完了'
  createdTime: string // ISO日時（無い場合は ''）
}

interface Progress {
  id: string
  box: number         // Leitnerボックス 0..5
  due: string         // 次回出題日 'YYYY-MM-DD'
  correct: number
  wrong: number
  lastSeen: string    // 最終学習日時 ISO（未学習は ''）
  learned: boolean    // 手動「覚えた」チェック（SRSの習得済みとは別）
}

type Grade = 'good' | 'vague' | 'bad'
```

### 3.2 永続化（IndexedDB: `my-phrases`, version 2）

| ストア | キー | 値 | 用途 |
|---|---|---|---|
| `phrases` | `id`（keyPath） | Phrase | 取り込んだフレーズ（空=サンプル使用） |
| `progress` | `id`（keyPath） | Progress | 学習進捗（フレーズと独立に保持・`learned` を含む） |
| `meta` | 任意キー | 任意 | `streak`（連続日数）, `lastStudyDate` |

- 設定（音声/速度/自動再生/出題数/対象ステータス/連続再生の各設定）は localStorage（キー: `my-phrases-settings`）。
- **進捗とフレーズは別ストア**。再インポートでフレーズを入れ替えても、同一IDの進捗（`learned` 含む）は維持される。

## 4. SRS仕様（`src/lib/srs.ts`）

Leitnerボックス方式。ボックス 0..5（`MAX_BOX = 5`）。

### 4.1 出題間隔（日）

| box | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| INTERVALS | 0 | 1 | 3 | 7 | 16 | 45 |

### 4.2 採点による遷移（`applyGrade`）

| 採点 | box変化 | 次回出題日（due） | 補足 |
|---|---|---|---|
| good（できた/言えた） | `min(box+1, 5)` | 今日 + INTERVALS[新box] | correct++ |
| vague（あいまい/もう一度） | 変更なし | 今日 + 1日 | 早期に再復習 |
| bad（できなかった） | 0 にリセット | 今日（= +0日） | wrong++ |

- `isDue(p)`: `p.due <= 今日`
- `isMastered(p)`: `box >= 5`
- `isNew(p)`: `lastSeen === ''`
- 「覚えた」（`learned`）は SRS とは独立した主観マークで、出題間隔の計算には影響しない。
- 日付は端末ローカル時刻基準の `YYYY-MM-DD`。

### 4.3 ストリーク（`useDeck.bumpStreak`）

- 採点時、`lastStudyDate` が当日でなければ更新。
- 前日に学習していれば `streak + 1`、そうでなければ `1` にリセット。

## 5. 出題・統計仕様（`src/lib/session.ts`）

### 5.1 今日の出題（`buildSession`）
1. 対象 = 設定の `includeStatuses` に合致し、`isDue` かつ `!isMastered` のフレーズ。
2. 並び順 = box昇順（弱いカード優先）→ due昇順。
3. 先頭から `sessionSize` 枚を採用。
4. `onlyUnsure` 指定時は `learned` 済みを除外する（発音練習の「自信なし」絞り込み）。
5. 0枚の場合は、対象ステータスのフレーズをシャッフルして `sessionSize` 枚（自由練習フォールバック、`useSession` 側）。

### 5.2 文数による振り分け（`src/lib/text.ts`）
- `sentenceCount(en)`: 終端記号（. ! ?）で分割して文数を数える（終端なしでも最低1文）。
- `isMultiSentence(en)`: 2文以上なら true。**モデリング**は `isMultiSentence` を満たすフレーズのみを対象とする。

### 5.3 統計（`computeStats`）

| 指標 | 定義 |
|---|---|
| due（今日の出題） | 対象かつ `isDue` かつ未習得 の件数 |
| newCount（新規） | `isNew` の件数 |
| mastered（習得済み） | `isMastered` の件数 |
| studiedToday（今日やった） | `lastSeen` の日付が当日 の件数 |
| total（登録） | 対象ステータスの総数 |

## 6. インポート仕様（`src/lib/import.ts`）

入口: `parsePhrasesFromFiles(files: File[]): Promise<Phrase[]>`

### 6.1 ファイル種別の処理

| 入力 | 処理 |
|---|---|
| `.zip` | fflate `unzipSync` で解凍し、`.md/.markdown/.txt/.csv` エントリのみ処理 |
| `.csv` | `fromCsv`（RFC4180準拠の簡易パーサ） |
| `.md/.markdown/.txt` | テーブル形式を優先（`fromMarkdownTable`）、無ければページ形式（`fromMarkdownPage`） |

複数ファイル・複数エントリの結果は **IDで重複排除**（後勝ち）。`en` と `ja` の両方が空の行は除外。

### 6.2 列・プロパティのマッピング

| Phrase | Notionプロパティ名 |
|---|---|
| en | `フレーズ`（CSVヘッダ / MD H1） |
| ja | `日本語訳` |
| example | `使用例（例文）` |
| status | `ステータス`（無ければ `未着手`） |

### 6.3 ID採番（`stableId` / `idFromFilename`）
- `.md`: ファイル名末尾の32桁hex（NotionページID）を使用。無ければ英文ハッシュ。
- `.csv` / hexなし: 英文の FNV-1a 32bit ハッシュ → `p_<hex>`。
- 同一英文なら常に同一IDとなり、再取り込み時に進捗が維持される。

### 6.4 保存（`useDeck.importFiles`）
1. `parsePhrasesFromFiles` で解析。0件なら例外（UIにエラー表示）。
2. `replacePhrases`（`phrases` ストアを clear → 全件 put、単一トランザクション）。
3. `load()` を再実行し、`source = 'imported'` で画面更新。

## 7. 状態管理仕様

### 7.1 デッキ（`src/store/useDeck.ts`）

| 状態 | 内容 |
|---|---|
| `phrases` | 表示中フレーズ（createdTime降順ソート） |
| `progress` | id→Progress のマップ |
| `streak` | 連続学習日数 |
| `source` | `'imported'` / `'sample'` |
| `loaded` / `error` | 読み込み状態 |

| アクション | 振る舞い |
|---|---|
| `load()` | 取り込み済みがあればそれを、無ければ `public/data/phrases.json` を読み、進捗とマージ |
| `grade(id, g)` | SRS更新→`progress`ストア保存→ストリーク更新 |
| `setLearned(id, v)` | フレーズの「覚えた」状態を更新→`progress`ストア保存 |
| `importFiles(files)` | インポート（§6.4）、取り込み件数を返す |
| `clearImported()` | `phrases`ストアを消去しサンプルへ戻す |
| `reset()` | 進捗・ストリークを全消去 |

### 7.2 設定（`src/store/useSettings.ts`、persist）

| キー | 既定値 | 説明 |
|---|---|---|
| `voiceURI` | null（端末既定） | TTS音声 |
| `rate` | 0.9 | 再生速度（**英語のみ適用**・日本語訳は常に等倍） |
| `autoPlay` | true | 解答時/出題時の自動読み上げ |
| `sessionSize` | 20 | 1セッション出題枚数（5〜50） |
| `includeStatuses` | 未着手/進行中/完了 | 練習対象ステータス |
| `repeat` | false | 連続再生: 末尾で先頭へ戻る |
| `shuffle` | false | 連続再生: ランダム順で再生 |
| `speakPhrase` | true | 連続再生: フレーズ（英語）を読み上げる |
| `speakExample` | false | 連続再生: 例文（英語）を読み上げる |
| `speakJa` | false | 連続再生: 日本語訳も読み上げる |

## 8. 画面仕様

ルーティングは HashRouter（`#/`, `#/compose`, `#/modeling`, `#/pronounce`, `#/browse`, `#/phrase/:id`, `#/settings`）。
下部ナビ（ホーム/一覧/設定）は表示。**練習・再生中（compose / modeling / pronounce / phrase）は下部ナビを非表示**にし、
固定ナビが操作ボタンと重ならないようにする（`BottomNav` の `HIDDEN_PREFIXES`）。
未TTS環境（API無し・音声0件）では上部に `SupportBanner`（Google TTS 導入案内）を表示する。

### 8.1 ホーム（`Home.tsx`）
- 統計カード（§5.3）とストリーク表示。
- 「⚡瞬間英作文（1文）」「📝モデリング（2文以上）」「🗣️発音練習」への遷移ボタン。
- `source === 'sample'` のときインポート導線バナーを表示。
- 今日の出題が0のとき完了メッセージを表示。

### 8.2 瞬間英作文（`Compose.tsx` + `useSession`）
1. 日本語訳を大きく表示。
2. 「答えを見る」で英語・再生ボタン・例文（任意）を表示。`autoPlay` なら英語を自動再生。
3. 3段階採点ボタン（✕/🔺/⭕）。`good` 以外はキュー末尾へ再投入。
4. キュー終了で結果サマリ（できた/あいまい/できなかった件数、ホーム/もう一度）。

### 8.3 モデリング・発音練習（`Modeling.tsx` / `Pronounce.tsx` + 共通 `ListenPractice`）
両画面は共通コンポーネント `ListenPractice` を設定違いで再利用する。
- お手本の英語と日本語訳を最初から表示し、出題時にお手本を自動再生（`autoPlay`）。「もう一度聞く」で再生し直し。
- 2段階採点（🔁もう一度=vague / ✅言えた=good）。`good` 以外はキュー末尾へ再投入。
- **モデリング**: `isMultiSentence`（2文以上）のフレーズのみを対象（`filter`）。
- **発音練習**（`practice`）: 🔀シャッフル / ⚠️自信なし の絞り込みチップと、各フレーズの「覚えた」チェックを表示。

### 8.4 一覧（`Browse.tsx`）
- 検索（en/ja部分一致）、絞り込みチップ（すべて / 自信なし / 未着手 / 進行中 / 完了）、件数表示。
- 各項目: 英語・日本語・習得済みマーク（✅）・「☐/☑覚えた」トグル・単発TTS再生（🔊）。
- 英語/日本語の部分をタップで**連続再生プレイヤー**（`/phrase/:id`）へ遷移し、
  そのとき**現在の絞り込み結果のID配列**を `location.state.ids` として渡す（再生範囲＝絞り込み結果）。

### 8.5 連続再生プレイヤー（`PhraseDetail.tsx`）
一覧から起動し、単体表示と自動連続再生を兼ねる。
- 表示: フレーズ（英）・日本語訳・例文。現在位置 `cursor+1 / order.length`。
- 再生順 `order`: `location.state.ids`（無ければ全フレーズ）を基に構築。`shuffle` 時はタップ起点を先頭固定でシャッフル（`shuffleKeepingFirst`）。
- 読み上げ単位 `buildParts`: フレーズ(英) → 日本語訳(日) → 例文(英) の順で、ONかつ非空の項目のみを連結。
- ▶自動再生 / ⏸停止。`speakParts` で各パートを順に読み、1カード終了後 **2秒の間**を空けて次へ進む。
  末尾到達時は `repeat` ON なら先頭へ、OFFなら停止。
- 🔁リピート / 🔀シャッフル、読み上げ項目（🔊フレーズ / 🔊例文 / 🇯🇵日本語訳）のトグル。
  日本語音声が端末に無い場合は日本語訳トグルを無効化し注記を表示（`hasVoiceForLang('ja')`）。
- ← 戻る / 進む →: 手動移動（停止中は `autoPlay` なら移動先を単発再生）。
- 連続再生中・暗転中は `useWakeLock` で画面スリープを抑止。
- **🌙暗くして再生（`DarkOverlay`）**: 全画面を黒く覆い、再生を継続したまま誤タッチを無効化。
  `onTouchStart` で `touches.length >= 2`（2本指同時）のときのみ解除、1本指は無効。再生停止で暗転も自動解除。
  ※バックライト自体はWebから消せないため見た目を黒くするのみ（§11参照）。

### 8.6 設定（`Settings.tsx`）
- 音声: 読み上げ音声選択 / 再生速度（変更時にテスト発話・英語のみ適用）/ 自動読み上げ。
- セッション: 出題枚数 / 対象ステータス。
- フレーズの取り込み: 現在データ表示（サンプル|取り込み済み / 件数）、手順説明、ファイル選択（`.zip,.csv,.md,.markdown,.txt`・複数可）、結果メッセージ、取り込み消去。
- データ: 学習進捗リセット（confirm確認あり）。

## 9. 音声仕様（`src/lib/tts.ts`）

- `loadVoices()`: `getVoices()`／`onvoiceschanged`／500msフォールバックで音声一覧を取得。
- `getEnglishVoices()`: `lang` が `en` で始まる音声に限定。`hasVoiceForLang(prefix)`: 指定言語の音声有無を判定。
- `resolveVoice(voiceURI, lang)`: 指定があり言語が一致すればその音声、無ければ言語先頭一致で自動選択。
  **オフラインでも鳴るよう `localService`（端末内蔵）音声を優先**する。
- `speak(text, {voiceURI, rate, lang})`: 既存発話を `cancel` 後に発話。`lang` 既定 `en-US`。
  **`rate` は英語のみ適用、日本語（ja）は常に等倍**。Androidの無音対策として `voice` オブジェクトを明示割当。
- `primeTTS()`: iOS Safari の音声アンロック。`App` で最初の `pointerdown` 時に一度実行。
- 未TTS環境（API無し / 音声0件）では `SupportBanner` を表示して案内する。

## 10. スリープ抑止仕様（`src/lib/wakeLock.ts`）

- `useWakeLock(active)`: `active` の間だけ Screen Wake Lock を取得し画面スリープを抑止。
- タブが裏に回ると Wake Lock は自動解放されるため、`visibilitychange` で復帰時に取り直す。
- 非対応端末・ユーザー操作外では黙って諦める（再生自体は継続）。
- 連続再生プレイヤーが `playing || dark` の間に使用する。

## 11. バージョン管理・配信仕様

- `vite.config.ts` の VitePWA（`registerType: autoUpdate`）でSW・manifestを生成。
- `phrases.json` は StaleWhileRevalidate でキャッシュ。アプリシェルはプリキャッシュ。

- スクリプト:
  - `npm run dev` 開発サーバ
  - `npm run build` 型チェック（`tsc --noEmit`）＋本番ビルド（`dist/`）
  - `npm run preview` 本番プレビュー

  - `deploy.yml`: main への push で `dist/` を GitHub Pages へ自動デプロイ。

  - 運用: `CHANGELOG.md` を更新し `npm run bump:*` で番号を上げ、PRをmainへマージするだけで採番される。

## 12. 既知の制約・注意

- 発音採点は自己申告（音声認識は未実装）。
- TTSの声・品質は端末依存。日本語訳の読み上げは日本語音声がある端末でのみ可能。
- `.csv` 取り込みはページIDを持たないため英文ハッシュIDを使用（英文変更で別フレーズ扱い）。
- インポートは全件置換方式（部分追記ではない）。
- **Web Speech API は画面消灯・タブ非表示で再生が停止する**ため、連続再生は画面点灯（Wake Lock）が前提。
- **「暗くして再生」はバックライトを物理的に消す機能ではない**（Webに明るさ制御APIが無い）。
  画面を黒く塗るのみで、有機ELなら実質消灯に近く、液晶では手動で明るさを下げると効果的。
- 完全な画面オフ・バックグラウンド再生には、実音声ファイル（MP3）＋ Media Session API 方式への移行が必要（将来拡張）。
