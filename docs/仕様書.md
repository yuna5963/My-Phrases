## 1. システム構成

クライアント完結型のPWA。サーバ・バックエンドを持たない。

```
[ブラウザ / PWA]
  ├─ UI（React + React Router(HashRouter)）
  ├─ 状態管理（Zustand: 設定 / デッキ）
  ├─ ロジック（SRS / セッション / TTS(連続読み上げ・間) / インポート解析 / Wake Lock）
  └─ 永続化（IndexedDB: チャンク・進捗・メタ / localStorage: 設定）
        ▲
        │ 取り込み（手動・1回限り）
[CSV（直接）/ Notionエクスポート（.zip / .md）]
```

### 1.1 技術スタック

| 領域 | 採用技術 |
|---|---|
| 言語 | TypeScript |
| UI | React 18 |
| ビルド | Vite 5 |
| ルーティング | react-router-dom（HashRouter） |
| スタイル | Tailwind CSS（darkMode: media） |
| 状態管理 | Zustand（設定はpersistでlocalStorage保存） |
| 永続化 | IndexedDB（idb ラッパ） |
| ZIP解凍 | fflate（ブラウザ内・オフライン） |
| 音声 | Web Speech API（SpeechSynthesis） |
| スリープ抑止 | Screen Wake Lock API（連続再生中のみ） |
| PWA | vite-plugin-pwa（Workbox / Service Worker） |

## 3. データモデル

### 3.1 型定義（`src/types.ts`）

```ts
interface Example {
  en: string          // 例文（英語）
  ja: string          // その日本語訳（空可）
  kana?: string       // シラブル音節カナ＋強勢（任意・CSVの「音節{n}」列。§8.9参照）
}

interface Phrase {
  id: string          // 安定キー（csv:ID列 / md:ページID / 旧:英文ハッシュ）
  en: string          // チャンク（見出しの語・型）
  ja: string          // チャンクの日本語訳
  kana?: string       // チャンク英語のシラブル音節カナ＋強勢（任意・CSVの「音節」列）
  examples: Example[] // 例文（最大5・各 en/ja/kana）。長文音読では本文を examples[0] に持つ
  type: string        // Nuance / Pattern / Chunk / Connector / Phrase / Long Reading（特別扱い）
  category: string    // Daily Status / Health / Work ...
  level: string       // Basic / Core / Advanced
  priority: string    // ★の数（例: ★★★★★）
  note: string        // 補足メモ（空可）
  status: string      // '未着手' | '進行中' | '完了'（新CSVに列が無い場合は '未着手'）
  createdTime: string // ISO日時（無い場合は ''）
}

interface Progress {
  id: string
  box: number         // Leitnerボックス 0..5
  due: string         // 次回出題日 'YYYY-MM-DD'
  correct: number
  wrong: number
  lastSeen: string    // 最終学習日時 ISO（未学習は ''）
  learned: boolean    // 手動「覚えた」チェック（SRSの習得済みとは別）
}

type Grade = 'good' | 'vague' | 'bad'
```

### 3.2 永続化（IndexedDB: `my-phrases`, version 2）

| ストア | キー | 値 | 用途 |
|---|---|---|---|
| `phrases` | `id`（keyPath） | Phrase | 取り込んだチャンク（空=サンプル使用） |
| `progress` | `id`（keyPath） | Progress | 学習進捗（チャンクと独立に保持・`learned` を含む） |
| `meta` | 任意キー | 任意 | `streak`（連続日数）, `lastStudyDate` |

- 設定（音声/速度/自動再生/出題数/対象ステータス/連続再生の各設定）は localStorage（キー: `my-phrases-settings`）。
- **進捗とチャンクは別ストア**。再インポートでチャンクを入れ替えても、同一IDの進捗（`learned` 含む）は維持される。
- **id 採番方式の変更（FNVハッシュ→CSVの `ID` 列）に伴い、旧データからの移行時は進捗キーが変わり一度リセットされる**点に注意（データ構造を再構成した新データセットのため）。

## 4. SRS仕様（`src/lib/srs.ts`）

Leitnerボックス方式。ボックス 0..5（`MAX_BOX = 5`）。

### 4.1 出題間隔（日）

| box | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| INTERVALS | 0 | 1 | 3 | 7 | 16 | 45 |

### 4.2 採点による遷移（`applyGrade`）

| 採点 | box変化 | 次回出題日（due） | 補足 |
|---|---|---|---|
| good（できた/言えた） | `min(box+1, 5)` | 今日 + INTERVALS[新box] | correct++ |
| vague（あいまい/もう一度） | 変更なし | 今日 + 1日 | 早期に再復習 |
| bad（できなかった） | 0 にリセット | 今日（= +0日） | wrong++ |

- `isDue(p)`: `p.due <= 今日`
- `isMastered(p)`: `box >= 5`
- `isNew(p)`: `lastSeen === ''`
- 「覚えた」（`learned`）は SRS とは独立した主観マークで、出題間隔の計算には影響しない。
- 日付は端末ローカル時刻基準の `YYYY-MM-DD`。

### 4.3 ストリーク（`useDeck.bumpStreak`）

- 採点時、`lastStudyDate` が当日でなければ更新。
- 前日に学習していれば `streak + 1`、そうでなければ `1` にリセット。

## 5. 出題・統計仕様（`src/lib/session.ts`）

### 5.1 今日の出題（`buildSession`）
1. 対象 = 設定の `includeStatuses` に合致し、`isDue` かつ `!isMastered` のフレーズ。
2. 並び順 = box昇順（弱いカード優先）→ due昇順。
3. 先頭から `sessionSize` 枚を採用。
4. `onlyUnsure` 指定時は `learned` 済みを除外する（発音練習の「自信なし」絞り込み）。
5. 0枚の場合は、対象ステータスのフレーズをシャッフルして `sessionSize` 枚（自由練習フォールバック、`useSession` 側）。
   ただし `useSession` に `noFallback: true` を指定した画面（今日の練習）ではこの補充を行わず、空のまま返す。
6. `clusterByFacet: true` 指定時（瞬間英作文）は、選ばれたキューを `clusterByTypeCategory` で **Type → Category** にまとめ直す
   （グループは弱い順での初出順、グループ内も弱い順を保持）。

### 5.1b 「今日の練習」の形式出し分け（`src/lib/dailyForm.ts` の `formFor`）

| 条件 | 形式 |
|---|---|
| 進捗なし or `isNew`（未学習） | `model`（モデリング） |
| box 0-1 | `repro`（再現練習） |
| box 4以上 かつ `hasCloze` | `cloze`（文脈穴埋め） |
| それ以外（box 2-3、または穴埋め不可） | `compose`（瞬間英作文） |

形式はカード表示のたびに最新の進捗から算出する（キューには id のみ保持）。そのため
採点で box が変化すると、同一セッション内の再出題（good 以外で末尾に再キュー）でも形式が追従する。

### 5.2 練習対象
- 旧「文数による振り分け（`text.ts`）」は廃止。瞬間英作文・発音練習・文脈穴埋め・今日の練習は**全チャンク**を対象とし、絞り込みは一覧のファセット（Type/Category/Level/Priority）や「自信なし」で行う。ただし `Type === 'Long Reading'` のフレーズは長文音読モード専用とし、これらのモード・各一覧・ホーム集計からは除外する（`excludeLongReading`）。

### 5.3 統計（`computeStats`）

| 指標 | 定義 |
|---|---|
| due（今日の出題） | 対象かつ `isDue` かつ未習得 の件数 |
| newCount（新規） | `isNew` の件数 |
| mastered（習得済み） | `isMastered` の件数 |
| studiedToday（今日やった） | `lastSeen` の日付が当日 の件数 |
| total（登録） | 対象ステータスの総数 |

## 6. インポート仕様（`src/lib/import.ts`）

入口: `parsePhrasesFromFiles(files: File[]): Promise<Phrase[]>`

### 6.1 ファイル種別の処理

| 入力 | 処理 |
|---|---|
| `.csv` | `fromCsv`（RFC4180準拠の簡易パーサ）。新フォーマット推奨 |
| `.zip` | fflate `unzipSync` で解凍し、`.md/.markdown/.txt/.csv` エントリのみ処理 |
| `.md/.markdown/.txt` | テーブル形式を優先（`fromMarkdownTable`）、無ければページ形式（`fromMarkdownPage`） |

複数ファイル・複数エントリの結果は **IDで重複排除**（後勝ち）。チャンク英語（`Chunk`/`フレーズ`）と和訳（`日本語`/`日本語訳`）の両方が空の行は除外。先頭セルのBOMは `trim()` で除去。

### 6.2 列・プロパティのマッピング

新CSVヘッダー契約（`音節` 系は任意。推奨は英・和の直後に音節を置く並び）:
```
ID,Type,Category,Level,Priority,Chunk,日本語,音節,Example1,日本語訳1,音節1,…,Example5,日本語訳5,音節5,Note
```

| Phrase | 新CSV列 | 旧Notion列（後方互換） |
|---|---|---|
| id | `ID` | （無ければ英文ハッシュ / MDはページID） |
| en | `Chunk` | `フレーズ`（CSVヘッダ / MD H1） |
| ja | `日本語` | `日本語訳` |
| kana | `音節`（任意。別名 `Chunk_Kana`/`Syllable` 等） | （無ければ空） |
| examples[n] | `Example{n}` + `日本語訳{n}` + `音節{n}`（音節は任意） | 単一 `使用例（例文）` 等 → 和訳なし1件 |
| type/category/level/priority/note | `Type`/`Category`/`Level`/`Priority`/`Note` | （無ければ空） |
| status | `ステータス`（無ければ `未着手`） | 同左 |

- 例文は `Example1`〜（連番が途切れるまで）を走査し、各 `Example{n}` と対応する `日本語訳{n}`（別名 `Example{n}_JA` 等）をペアにする。`Example{n}` が空のペアは飛ばす。
- `音節` / `音節{n}`（別名 `Example{n}_Kana`/`カナ{n}` 等）はシラブル音節カナ＋強勢。空欄可（後方互換）。記法は §8.9 と `docs/シラブル音節記法.md` を参照。

### 6.3 ID採番（`makePhrase` / `stableId` / `idFromFilename`）
- `ID` 列があればそのまま採用（例: `MP001`）。
- `.md`: ファイル名末尾の32桁hex（NotionページID）を使用。
- それ以外: 英文（チャンク）の FNV-1a 32bit ハッシュ → `p_<hex>`。

### 6.4 保存（`useDeck.importFiles`）
1. `parsePhrasesFromFiles` で解析。0件なら例外（UIにエラー表示）。
2. `replacePhrases`（`phrases` ストアを clear → 全件 put、単一トランザクション）。
3. `load()` を再実行し、`source = 'imported'` で画面更新。

## 8. 画面仕様

ルーティングは HashRouter（`#/`, `#/daily`, `#/compose`, `#/pronounce`, `#/long-reading`, `#/cloze`, `#/browse`, `#/examples`, `#/chunk/:id`, `#/phrase/:id`, `#/settings`）。
下部ナビ（ホーム/チャンク一覧/例文一覧/設定）は表示。**練習・再生中（daily / compose / pronounce / long-reading / cloze / phrase）は下部ナビを非表示**にし、
固定ナビが操作ボタンと重ならないようにする（`BottomNav` の `HIDDEN_PREFIXES`）。
未TTS環境（API無し・音声0件）では上部に `SupportBanner`（Google TTS 導入案内）を表示する。

### 8.1 ホーム（`Home.tsx`）
- 統計カード（§5.3）とストリーク表示。
- 統計直下に**「▶ 今日の練習」**（§8.10）への最上位導線。期日到来件数（`stats.due`）を説明文に併記し、0件時は完了の旨を表示。
- 「⚡瞬間英作文」「🗣️発音練習」「🧩文脈穴埋め」「📖長文音読」への遷移ボタン（説明文はチャンク+例文ベース）。モデリングは発音練習と重複のため v0.6 でモードとしては削除（「今日の練習」のモデリング形式として継続）。
- `source === 'sample'` のときインポート導線バナーを表示。
- 今日の出題が0のとき完了メッセージを表示。

### 8.2 瞬間英作文（`Compose.tsx` + `useSession`）
1. `useSession({ clusterByFacet: true })`: SRSで選んだキューを **Type → Category でまとめ直し**、同じタイプ・同じカテゴリのチャンクへ優先的に遷移する（`clusterByTypeCategory`、§5.1）。
2. 1チャンク＝**チャンク → 例文1 → … → 例文5 の逐次練習**（共通 `ReproCard` に `chunkAndExampleItems(phrase)` を渡す。和訳のない例文はスキップ）。
   各項目は「日本語訳表示＋読み上げ → タッチ → 英文＋カナ表示＋読み上げ → タッチで次項目」。英文はタッチまで非表示・自動送りなし。カード上部に項目の進み（n/総数）と `MetaChips`。
   開示した英文の下に**「🔊 もう一度」再生ボタン**（`stopPropagation` でカード送りには伝播しない。`ReproCard` 共通＝今日の練習・フレーズ再生の再現練習でも同様）。
3. **最後の項目の英文を開示したら**3段階採点ボタン（✕/🔺/⭕、共通 `GradeButtons`）を表示（`onStep` で末尾開示を検知）。`good` 以外はキュー末尾へ再投入。
4. キュー終了で結果サマリ（できた/あいまい/できなかった件数、ホーム/もう一度）。
5. 片手操作のため「✕ やめる」は画面**最下部**に配置（上部ヘッダー `SessionHeader` はタイトルと進捗のみ）。`StepNav`（← 戻る / 進む →）の下に置く。

### 8.3 発音練習（`Pronounce.tsx` + 共通 `ListenPractice`）
対象は**全チャンク**。（旧モデリングモードは実装・目的が重複のため v0.6 で削除し本モードへ統合）
- チャンク英語・日本語訳・メタ（`MetaChips`）・5例文（英＋和）を最初から表示（共通 `ModelCard`）。
- 出題時の自動再生（`autoPlay`）は**チャンクのみ**。「🔊お手本を聞く」で **`speakSequence` の「チャンク→例文1→…」を間2秒**で連続読み上げ（`modelParts`）、**再生中は「⏸停止」トグル**で中断できる（トークン＋`onDone` で再生状態を管理）。各例文は個別再生も可。
- 2段階採点（🔁もう一度=vague / ✅言えた=good）。`good` 以外はキュー末尾へ再投入。
- 🔀シャッフル / ⚠️自信なし の絞り込みチップと、各チャンクの「覚えた」チェックを表示。
- 片手操作のため「✕ やめる」は画面**最下部**（`StepNav` の下）に配置。上部ヘッダー `SessionHeader` はタイトルと進捗のみ。

### 8.4 長文音読（`LongReading.tsx`）
`Type === 'Long Reading'`（`isLongReading` / `LONG_READING_TYPE`）のフレーズのみを対象に、長文本文をお手本として読み上げ、続けて音読する練習。長文は本文・和訳を1つずつ持つ（`examples[0]` が本文。Example2 以降は空欄）。
- 対象は `phrases.filter(isLongReading)`。本文は `current.examples[0]`。`SessionHeader`（SRSキュー）は使わず、`pos`（0..n-1）でカードを送る独自の状態管理。
- ヘッダー（独自 `Header`）はタイトル「長文音読」と進捗（`pos+1 / total`）のみ。
- 本文領域だけを縦スクロール（`overflow-y-auto`）させ、「🔊お手本を聞く」ボタンは常時見える位置に固定。
- 「🔊お手本を聞く / ⏸停止」: 本文（英文）を `speak` で1回読み上げ（`onEnd`/`onError` で停止状態へ戻す）。再生中は `useWakeLock` で画面スリープを抑止。
- 「訳を見る / 訳を隠す」で和訳（`examples[0].ja`）をトグル表示。カード送り（`pos` 変更）・離脱時は読み上げ停止・訳表示リセット。
- カード送りは共通 `StepNav`（← 戻る / 進む →）。片手操作のため「✕ やめる」は画面**最下部**（`StepNav` の下）に配置。
- 対象が0件のときは取り込み案内（「Type が『Long Reading』のフレーズを取り込むと表示」）と「ホームへ戻る」を表示。
- 長文音読の対象（`Long Reading`）は瞬間英作文・発音練習・各一覧・ホーム集計からは除外される（`excludeLongReading`）。

### 8.5 チャンク一覧（`Browse.tsx`）
- 検索（チャンク英語 / 日本語 / 例文の英・和の部分一致）、件数表示。
- 絞り込み: 「⚠️自信なし」トグルと、**Type / Category / Level / Priority のファセット行**（値はデータから動的生成、各ファセット1値選択・横断AND）。検索と絞り込みは共通フック `usePhraseFilter` ＋ 共通UI `FacetFilters` を例文一覧と共有する。
- 各項目: チャンク英語・日本語・習得済みマーク（✅）・「☐/☑覚えた」トグル・単発TTS再生（🔊）・連続再生直行（▶）。
- 項目をタップで**チャンク詳細**（`/chunk/:id`、§8.11）へ、**▶ボタンで連続再生プレイヤー**（`/phrase/:id`）へ直接遷移する。
  どちらも**現在の絞り込み結果のID配列**を `location.state.ids`、戻り先を `location.state.backTo`（`/browse`）として渡す（再生範囲＝絞り込み結果）。

### 8.6 例文一覧（`Examples.tsx`）
- チャンク一覧と**同一の上部フィルタ**（検索 / 自信なし / ファセット）を `usePhraseFilter` ＋ `FacetFilters` で流用。
- 絞り込み済みチャンクの例文1〜5を**平坦に展開**して一覧表示（英文＋日本語訳。空の例文は除外）。出典として「例文N・チャンク英語」を併記。
- 件数が多いため**ページング**（1ページ30件、前後ボタンと「現在/総ページ」表示）。フィルタ変更時は先頭ページへ戻す。
- 各行をタップで親チャンクの**チャンク詳細**（`/chunk/:id`、§8.11）へ遷移（`location.state.ids` ＝絞り込み結果、`backTo` ＝ `/examples`）。各行に例文単体の単発TTS再生（🔊）。連続再生へは詳細画面の「▶ 連続再生」から。

### 8.7 連続再生プレイヤー / 再現練習（`PhraseDetail.tsx`）
チャンク一覧・例文一覧から起動し、単体表示・自動連続再生・再現練習を兼ねる。
- 再生順 `order`: `location.state.ids`（無ければ全チャンク）を基に構築。`shuffle` 時はタップ起点を先頭固定でシャッフル（`shuffleKeepingFirst`）。現在位置 `cursor+1 / order.length`。
- 「← 一覧へ」は `location.state.backTo`（既定 `/browse`）へ戻る＝起動元の一覧（チャンク/例文）に応じて遷移先を切替。片手操作のため画面**最下部**（← 戻る / 進む → の下）に配置し、上部ヘッダーはタイトルと進捗のみ。
- **項目（`buildItems`）**: チャンク（`speakPhrase`）→各例文（`speakExample`）。各項目は en/ja を持つ。
- **読み上げ列 `buildParts`**: 日本語訳ON（`speakJa`）なら各項目を **「和訳→英文」**、OFFなら英文のみで連結。
  **間（`SeqPart.gapAfter`）は 1項目内（和訳↔英文）=1.5秒、次の項目へ=2秒**（`GAP_EN_JA` / `GAP_NEXT`）。最後は間なし。
- **▶自動再生 / ⏸停止**: `speakSequence` で読み、1カード終了後さらに **2秒**空けて次のチャンクへ。末尾到達時は `repeat` ON なら先頭へ、OFFなら停止。
- **🌙暗くして再生（`DarkOverlay`）**: 全画面を黒く覆い、再生を継続したまま誤タッチを無効化。
  `onTouchStart` で `touches.length >= 2`（2本指同時）のときのみ解除、1本指は無効。再生停止で暗転も自動解除。
  ※バックライト自体はWebから消せないため見た目を黒くするのみ（§11参照）。
- **再現練習（reproActive = 停止中 かつ `speakJa` ON かつ 項目あり）**: カードを共通 `ReproCard` の単項目フォーカス表示に切替。
  「日本語訳のみ表示＋再生 → カードをタッチ → その項目の英文を表示＋再生 → **タッチで次項目の日本語訳へ**」。自動送りはしない。
  英文はタッチするまで非表示。項目送り・英文公開はどちらもカードのタッチ、チャンク間の移動は 戻る/進む。`ReproCard` 内のドライバ effect が音声を駆動する（瞬間英作文の「例文を見る」と同一実装）。
- 🔁リピート / 🔀シャッフル、読み上げ項目（🔊チャンク / 🔊例文 / 🇯🇵日本語訳）のトグル。
  日本語音声が端末に無い場合は日本語訳トグルを無効化し注記を表示（`hasVoiceForLang('ja')`）。
- ← 戻る / 進む →: 手動移動（停止中で `speakJa` OFF かつ `autoPlay` なら移動先を単発再生。`speakJa` ON時は再現練習ドライバが先頭から駆動）。
- 連続再生中・暗転中は `useWakeLock` で画面スリープを抑止。

### 8.8 設定（`Settings.tsx`）
- 音声: 読み上げ音声選択 / 再生速度（変更時にテスト発話・英語のみ適用）/ 自動読み上げ / **カナ（音節）を表示**（`showKana` トグル）。
- セッション: 出題枚数 / 対象ステータス。
- 取り込み: 現在データ表示（サンプル|取り込み済み / 件数）、**①CSV直接（列構成を明記。`音節`/`音節1〜5` を含む）/ ②Notionエクスポート(.zip)** の2案内、ファイル選択（`.csv,.zip,.md,.markdown,.txt`・複数可）、結果メッセージ、取り込み消去。
- データ: 学習進捗リセット（confirm確認あり）。

### 8.9 シラブル音節カナ表示（共通 `KanaLine.tsx`）
英文の発音学習補助として、英文の**下**に小さくシラブル音節カナを添える横断要素。`Phrase.kana` / `Example.kana`（CSVの `音節`/`音節{n}` 列）を表示する。
- 表示条件: 設定 `showKana` が ON **かつ** 当該 `kana` が非空のときのみ描画（空・未入力なら英文だけ）。
- 強勢: カナ文字列中の `*…*` で囲まれた部分を太字＋濃色（`font-semibold`・`text-slate-600`）で描画。`*` 自体は区切りとして消費し表示しない。
- 表示範囲: **カード/詳細/練習画面のみ**＝瞬間英作文（`ReproCard` の開示英文）/ 発音練習 / 今日の練習 / 文脈穴埋め / チャンク詳細 / 長文音読 / フレーズ再生（非再現カード・再現練習 `ReproCard`）。**チャンク一覧・例文一覧（一覧行）は対象外**（コンパクト表示維持）。
- 記法（`・`音節区切り / 半角空白=単語区切り / `‿`リンキング / `( )`脱落音 / `*…*`強勢）の詳細・作成手順・ChatGPT量産プロンプトは `docs/シラブル音節記法.md` に規定。

### 8.10 今日の練習（`Daily.tsx`）
SRSの期日到来カードを、習熟度に応じた練習形式で自動出題する統合セッション。
- セッション: `useSession({ noFallback: true })`。期日到来カードが0件のときは補充せず「今日の練習はすべて完了です 🎉」＋ホームへ戻る導線を表示（§5.1）。
- 形式の出し分けは `formFor(progress[id], phrase)`（§5.1b）。現在の形式（📝モデリング / 🔁再現練習 / ⚡瞬間英作文 / 🧩文脈穴埋め）を `SessionHeader` 直下にラベル表示。
- **model**: 共通 `ModelCard`（チャンク+カナ+和訳+メタ+例文、個別🔊）＋「🔊お手本を聞く / ⏸停止」トグル（`modelParts` を `speakSequence` 間2秒、トークンでカード切替時に中断）＋2段階採点（🔁もう一度=vague / ✅言えた=good）。`autoPlay` 時はカード表示で**チャンクのみ**自動再生。
- **repro**: 共通 `ReproCard` に**チャンク1項目**（en/ja/kana）を渡す。英文公開（`onStep` で検知）後に3段階採点 `GradeButtons` を表示。
- **compose**: 瞬間英作文（§8.2）と同じ逐次練習（`ReproCard` + `chunkAndExampleItems`: チャンク→例文1〜5）。最後の項目を開示したら `GradeButtons`。
- **cloze**: 共通 `ClozeCard`（§8.12 と同じ挙動）。開示後に `GradeButtons`。
- 採点は既存 `useSession.answer`（`useDeck.grade` → SRS）に統合。`good` 以外は末尾へ再キューされ、box の変化に応じて再出題時の形式も変わる。
- カード送りは `StepNav`、「✕ やめる」は画面最下部。カード切替・離脱時は読み上げを停止（トークン＋`stopSpeaking`）。

### 8.11 チャンク詳細（`ChunkDetail.tsx`）
チャンクの情報と学習の記録を確認する閲覧画面（下部ナビは表示したまま）。
- 表示: 共通 `ModelCard`（英語+カナ+和訳+メタ+例文・個別🔊）、note（あれば枠囲み）、学習の記録カード。
- 学習の記録: 習熟度 `box / 5`・「できた」（correct）・「できなかった」（wrong）・次回出題のひと言（未学習（新規）/ 今日出題 / 次回 YYYY-MM-DD / 習得済み✅）・「☐/☑覚えた」トグル（`setLearned`）。
- アクション（画面下部）: 「← 一覧へ」（`location.state.backTo`、既定 `/browse`）と「▶ 連続再生」（`/phrase/:id` へ、受け取った `ids`/`backTo` をそのまま転送）。
- 対象IDが見つからないときはフォールバック表示（「フレーズが見つかりませんでした」＋一覧へ戻る）。

### 8.12 文脈穴埋め（`Cloze.tsx` + `src/lib/cloze.ts`）
例文中のチャンクを伏せ字にして、文脈と日本語ヒントからチャンクを想起する練習。
- マッチング（`findChunkSpan`）: 大文字小文字無視＋**単語境界チェック**の部分一致（`in` が `going` に一致しない）。アポストロフィの字種差（`'`/`’`）は正規化して吸収。**活用形の探索（ステミング）はしない**＝見つからない例文は対象外。
- 出題対象: `useSession({ filter: hasCloze })`＝マッチ例文を1つ以上持つフレーズのみ。**1チャンク=1問**とし、マッチ例文からランダムに1つ選ぶ（同一カード表示中は固定）。進捗がチャンク単位のため、複数例文の連続出題で box が不当に進むのを避ける。
- カード（`ClozeCard`）: 伏せ字（固定 `____`、強調色）入り英文＋例文和訳＋ヒント（チャンクの日本語）→「答えを見る」で全文（チャンク部分を強調）＋カナ＋再生ボタン。`autoPlay` なら開示時に例文全文を自動再生。
- 開示後に3段階採点（`GradeButtons`）。`good` 以外は末尾へ再投入。対象0件なら「穴埋めにできる例文がありません」を表示。
- 純関数（`findChunkSpan` / `maskChunk` / `clozeItems` / `hasCloze`）は `src/lib/cloze.test.ts` でユニットテスト（`npm test`、vitest）。

## 9. 音声仕様（`src/lib/tts.ts`）

- `loadVoices()`: `getVoices()`／`onvoiceschanged`／500msフォールバックで音声一覧を取得。
- `getEnglishVoices()`: `lang` が `en` で始まる音声に限定。`hasVoiceForLang(prefix)`: 指定言語の音声有無を判定。
- `resolveVoice(voiceURI, lang)`: 指定があり言語が一致すればその音声、無ければ言語先頭一致で自動選択。
  **オフラインでも鳴るよう `localService`（端末内蔵）音声を優先**する。
- `speak(text, {voiceURI, rate, lang})`: 既存発話を `cancel` 後に発話。`lang` 既定 `en-US`。
  **`rate` は英語のみ適用、日本語（ja）は常に等倍**。Androidの無音対策として `voice` オブジェクトを明示割当。
- `speakSequence(parts, {voiceURI, rate, gapMs, isCancelled, onDone})`: `SeqPart[]`（`{text, lang?, gapAfter?}`）を順に発話。
  各パート後の間は `gapAfter`（無ければ共通 `gapMs`）。`isCancelled()` が真になると即中断。連続再生・発音練習/今日の練習のお手本再生で使用。
- `primeTTS()`: iOS Safari の音声アンロック。`App` で最初の `pointerdown` 時に一度実行。
- 未TTS環境（API無し / 音声0件）では `SupportBanner` を表示して案内する。

## 10. スリープ抑止仕様（`src/lib/wakeLock.ts`）

- `useWakeLock(active)`: `active` の間だけ Screen Wake Lock を取得し画面スリープを抑止。
- タブが裏に回ると Wake Lock は自動解放されるため、`visibilitychange` で復帰時に取り直す。
- 非対応端末・ユーザー操作外では黙って諦める（再生自体は継続）。
- 連続再生プレイヤーが `playing || dark` の間に使用する。

## 12. 既知の制約・注意

- 発音採点は自己申告（音声認識は未実装）。
- TTSの声・品質は端末依存。日本語訳の読み上げ・再現練習は日本語音声がある端末でのみ有効。
- CSVは `ID` 列を id に採用。`ID` 列が無い旧データは英文ハッシュIDで代替（英文変更で別チャンク扱い）。
- 例文の日本語訳は元データ側（`日本語訳{n}` 列）に持たせる。空の場合は再現練習・和訳読み上げでその項目をスキップ。
- インポートは全件置換方式（部分追記ではない）。
- **Web Speech API は画面消灯・タブ非表示で再生が停止する**ため、連続再生は画面点灯（Wake Lock）が前提。
- **「暗くして再生」はバックライトを物理的に消す機能ではない**（Webに明るさ制御APIが無い）。
  画面を黒く塗るのみで、有機ELなら実質消灯に近く、液晶では手動で明るさを下げると効果的。
- 完全な画面オフ・バックグラウンド再生には、実音声ファイル（MP3）＋ Media Session API 方式への移行が必要（将来拡張）。
